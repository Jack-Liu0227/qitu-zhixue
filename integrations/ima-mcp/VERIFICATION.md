# 验证记录

验证环境：Windows、Node.js v24.15.0、npm 11.12.1。

已完成：

- TypeScript 编译与类型检查通过。
- `npm.cmd test`：16 项测试全部通过，0 失败。
- 两个独立 MCP SDK 客户端分别携带自己的 token，并发完成初始化、列工具、检索同一知识库和读取 PDF 第二页。
- stdio 子进程完成 MCP 初始化、工具发现；标准输出未混入配置提示。
- API 请求使用官方域名、POST、正确的 Client ID / API Key 请求头及 UTF-8 JSON；非零业务错误码不会当成成功。
- 验证未授权知识库、伪造引用、无效 token、未授权 Origin/Host、超大请求和参数错误会被拒绝。
- PDF 使用本地生成的两页测试文件验证实际文字提取；原文下载在连接前拒绝内网和云元数据地址。
- PowerShell 配置脚本通过语法解析。

以上自动化测试中的 ima API 响应是根据官方文档构造的模拟数据，PDF 是本地测试文件；真实接口验证另外进行，见下文。

## 真实 ima 接口验收

- 使用用户最后一条消息中提供的凭证，保存在受保护的本地 `.env`，未输出到运行日志或加入源码包。
- 官方知识库列表接口返回“高中数学、物理、化学”三个个人知识库。
- 适配真实列表返回的 `kb_id` / `kb_name` 字段，并允许知识库 ID 中的 Base64 填充字符 `=`。
- 数学知识库资料列表返回 6 项（5 份教材及 1 份使用指南）。关键词“数学”返回 5 份教材；“对数”返回空结果。
- `npm.cmd run smoke` 通过真实 MCP 服务完成初始化、列工具、知识库查询、教材搜索、原文下载和 PDF 文字提取，退出码 0。
- `node examples/agent-client.mjs`：两个不同 token 的客户端并发连接同一服务，各自搜索到 5 份数学教材，退出码 0。
- 真实搜索可能不返回分页字段，服务已适配为无下一页，不会重复请求第一页；已增加对应回归测试。
- 当前本地 MCP 地址为 `http://127.0.0.1:8787/mcp`，默认只监听本机。已为数学、规划、答疑三个客户端分别生成实际连接配置，位于 `.runtime/clients/`。

进一步的教材内部页验收结果保存在本机 `.runtime/live-verification.json`，仅记录知识库名称、资料数量、客户端结果数量、教材标题和提取字数，不记录 token、API Key、正文或原文签名链接。

该记录已生成：数学 6 项、物理 6 项、化学 5 项；两个客户端各命中 5 份数学教材；数学必修第一册共 270 个 PDF 文件页，第 10 页提取了 997 字符，验证命令退出码 0。

Docker、HTTPS 反向代理和远程服务器尚未部署验收；公式识别准确性、扫描件 OCR 和 LLM 最终回答质量未验收。现有关键词搜索不能保证全文知识点召回。

测试期间没有调用 ima 的写入、上传或删除接口，没有修改用户知识库，也没有修改启途智学网站或服务器。
