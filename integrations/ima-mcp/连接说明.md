# ima MCP 连接说明

本工作区已完成本地配置和真实调用验证，后台服务正在运行。

| 配置项 | 值 |
|---|---|
| 协议 | MCP Streamable HTTP |
| 服务地址 | `http://127.0.0.1:8787/mcp` |
| 授权知识库 | 高中数学、高中物理、高中化学 |
| 认证 | 每个客户端各自的 Bearer token |

已生成的实际客户端配置：

- 数学 Agent：`.runtime/clients/1-math-agent.json`
- 学习规划 Agent：`.runtime/clients/2-planner-agent.json`
- 答疑 Agent：`.runtime/clients/3-tutor-agent.json`

将对应文件的 MCP 配置加入各 Agent 客户端即可；部分客户端字段命名不同，按其要求填写 Streamable HTTP 地址和 Authorization 请求头。这些配置含各 Agent 自己的访问 token，不含 ima API Key，请仅供对应客户端使用。

服务提供 `ima_list_knowledge_bases`、`ima_search_knowledge`、`ima_list_documents`、`ima_read_document` 四个工具。

已验证：两个独立客户端各自搜索到 5 份数学教材；数学必修第一册共 270 个 PDF 文件页，第 10 页提取了 997 字符。三个知识库资料列表分别有数学 6 项、物理 6 项、化学 5 项。

限制：本机地址只对当前电脑可用；其他电脑/服务器上的 Agent 需要部署后的 HTTPS 地址。当前关键词“对数”没有搜索结果，不能保证任意正文知识点直接召回；可以按书名定位教材后读取目录和原文。公式和扫描件识别没有验收。

电脑重启后，在本项目目录执行 `npm.cmd start` 重新启动。不要在当前后台实例仍占用 8787 端口时重复启动。部署方式和完整说明见 `README.md`。
