## 🔍 关键词索引

### 技术栈
- **前端**：Next.js 15, React 18, TypeScript 5.8, Tailwind CSS
- **后端**：FastAPI, Python 3.11+, LangChain, LangGraph
- **数据库**：PostgreSQL 15, Redis 7
- **AI 模型**：GPT-4o-mini, GPT-4o

### 核心概念
- **Agent Loop**：单一编排引擎（DeepTutor 复用）
- **三层记忆**：L1 实体镜像 / L2 阶段摘要 / L3 综合画像
- **SOUL.md**：AI 导师人格定义
- **ask_user**：结构化提问机制
- **七大能力**：Ask Questions, Quiz, Solve, Research, Visualize, Project Coach, Co-Writer
- **人工介入**：5 种触发条件（连续失败/情绪信号/安全操作/低置信度/关键节点）

### 开发相关
- **Monorepo**：Turborepo + pnpm workspace
- **Apps**：student-center, parent-companion, teacher-workspace, admin-console, ai-tutor-service
- **数据库表**：32+ 张表（15 核心业务 + 7 AI 搭档 + 6 成长档案 + 4 AI 配置）
- **前端组件**：23 个 React 组件（7 AI 对话 + 6 能力交互 + 5 项目管理 + 5 成长档案）
