# 启途智学 Logo

这里是项目的专用 Logo 目录。页面统一通过 `BrandMark` 和 `BrandLogo` 引用，不从 docs 加载图片。

- `source.png`：用户提供的原图，原样保留。
- `full.png`：收紧外围空白后的完整 Logo，包含图形、中英文品牌名，供登录页等完整品牌位置使用。
- `mark.png`：同一 Logo 的现有透明纯图形标志，供侧边栏品牌名旁使用。
- `receipt.json`：来源哈希、裁剪提示词及运行图片哈希。

原始设计保持为唯一品牌身份。导航功能图标由独立导航图片负责，不能使用 Logo 或以机器人头像替代品牌标志。
