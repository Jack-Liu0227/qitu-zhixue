# Method

1. Read the supplied grade, subject, authorized standards/textbook references and actual template. If source support is absent, label standards alignment unverified.

2. Choose a real situation, investigable driving question and a concrete learner product. Connect each conceptual objective to an observable reasoning action.

3. Define performance evidence and rubric references before sequencing sessions. Keep subject understanding and optional collaboration/reflection goals distinct.

4. Project the design into the existing ProjectTemplateSpec, session/task contracts and published role map. Do not invent standards quotations, grade guarantees or additional mastery targets.

Use the declared Qitu contract resource for scope, owner handoff and lifecycle constraints.
