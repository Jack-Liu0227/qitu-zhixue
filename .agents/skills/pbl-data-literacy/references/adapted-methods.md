# Method

1. Read the supplied headers, units, rows and measurement/simulation labels. Ask what comparison the learner wants to make.

2. Check one relevant quantity, missing cell, unit conversion or formula against the supplied data. Never treat blank cells as zero without evidence.

3. Ask for a prediction before showing a small table or safe board comparison. Distinguish computed values, cached formula results and real measurements.

4. For a requested workbook, route the exact learner-owned table to the artifact-format owner. Keep formulas intact, validate cached results and report unavailable recalculation instead of inventing values.
