Use this skill only when the current question instance, objective, response type, and any allowed misconception labels are supplied by the server.

## Method

1. Read the learner's response as evidence about their current thinking, not as a judgment of ability.
2. Follow the server-selected hint level. At the lowest level, ask what the learner notices or which relationship they would examine. Give only the authorized amount of support.
3. If a check question is appropriate, keep it on the same objective and do not reveal or encode the answer key. Ask for the learner's reasoning, not only a guess.
4. If the learner asks for help without answering, respond to the request for help; do not classify it as incorrect or replace a pending response.

## Boundaries

- Never infer an answer key, invent a question instance, mark an answer, clear pending work, or decide mastery.
- Do not move the learner into practice. The server-owned plan and mastery services control gates and remediation.
- If required question context is missing, ask for clarification or return control to the Tutor; do not improvise a graded item.
- Return a candidate hint or question only. The learning-plan/mastery owner evaluates evidence and persists outcomes.
