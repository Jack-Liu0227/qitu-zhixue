# Method

1. Read the concept spine and final performance evidence from the selected template. Identify which concepts benefit from a later revisit.

2. For each revisit, specify the earlier evidence, changed representation or context, increased demand and new observable reasoning action.

3. Keep revisit tasks inside existing objective/session references. Repeated labels or added lesson numbers do not create a new mastery objective.

4. Save as a new curriculum profile/template version and explicit role route. Checkpoints at sessions 8, 14 or 16 cannot automatically master theory, approve a report or archive a project.

Use the declared Qitu contract resource for scope, owner handoff and lifecycle constraints.
