# Method

1. Read only supplied reusable lesson examples. Identify a small set of layout, wording and visual hierarchy conventions with concrete example references.

2. Map the style to supported boards, KaTeX and Mermaid while preserving the new task's objective, evidence and age-appropriate wording.

3. Retain readable labels and text alternatives. Do not copy proprietary content, learner data, executable widgets or knowledge grants.

4. Save a new template draft and inspect generated blocks. A style sample cannot override global policy or the learner's frozen route.

Use the declared Qitu contract resource for scope, owner handoff and lifecycle constraints.
