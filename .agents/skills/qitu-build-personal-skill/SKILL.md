# Method

1. Inspect only the authorized teacher artifacts and bounded summaries explicitly supplied for this request. Do not enumerate student conversations.

2. Choose varied examples, identify a provisional preference and look for a counterexample. Distinguish observed patterns from desired future behavior.

3. Present the supporting artifact/version references and let the teacher correct or reject the pattern. Do not infer personality or universal pedagogy from a single lesson.

4. Create a governed skill draft using the existing skill owner. A proposed personal style cannot alter global policy, curriculum goals, knowledge grants or historical bindings.

Use the declared Qitu contract resource for scope, owner handoff and lifecycle constraints.
