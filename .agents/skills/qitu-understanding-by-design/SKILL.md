# Method

1. Define the intended conceptual understanding and an investigable essential question from authorized subject material.

2. Specify the learner's performance task, audience, product, evidence and rubric references before arranging learning experiences.

3. Connect each session task to the required evidence and a feedback/retry path. Keep optional reflection and collaboration goals distinct from theory gates.

4. Write the design into the existing ProjectTemplateSpec and new version. Route all publication, binding and assessment decisions through their existing owners.

Use the declared Qitu contract resource for scope, owner handoff and lifecycle constraints.
