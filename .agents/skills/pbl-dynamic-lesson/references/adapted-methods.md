# Method

1. Read the frozen lesson, current objective, allowed interaction domain, pending question and learner response. Select one mechanism or relationship to explore.

2. Ask for a prediction, then call tutor_propose_lesson_activity with one supported board, choice_question or registered optics candidate. The canonical tool ID is tutor.propose_lesson_activity.

3. Boards use bounded node/edge data or TeX, never HTML/JS/iframe. Choice questions require authorized evidence_ref values; keep correctOptionIndex and explanation private before submission.

4. Only registered single-slit diffraction and closed fine-mist scattering models may run, within the server domain and practice gate. Ask what changed and why after the operation.

5. Wait for the owner receipt before stating that a candidate or observation was saved. A slider change, generated board or run never directly completes a lesson or establishes mastery.

6. Select a small comparison, relationship map or formula from the supplied objective and evidence. Decide what the learner should notice.

7. Keep labels, units, scale, uncertainty and observation type explicit. Use narrow-screen readable content and a plain-language text alternative.

8. Emit supported board/KaTeX/Mermaid data only, or propose through the authorized dynamic activity channel. Do not generate SVG, HTML, CSS or external embeds.

9. Ask a reasoning question about the visual before adding more content. Decorative polish and generated visuals never count as evidence of mastery.
