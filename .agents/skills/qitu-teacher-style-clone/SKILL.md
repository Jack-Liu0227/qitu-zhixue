# Method

1. Use teacher-owned examples to separate content facts from optional teaching preferences such as question length or example sequencing.

2. Describe a provisional pattern with example references and let the teacher correct it. Avoid identity imitation or unsupported claims about teaching effectiveness.

3. Translate accepted preferences into bounded assistant instructions and a reviewed skill draft. Preserve server-selected hint levels and learner-first reasoning.

4. Publish through existing Admin owners and a new team version. Teacher style cannot disclose answers, change mastery criteria or expand access to student information.

Use the declared Qitu contract resource for scope, owner handoff and lifecycle constraints.
