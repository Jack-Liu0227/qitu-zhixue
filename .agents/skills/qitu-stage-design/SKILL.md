# Method

1. Read the actual template phase and session scope. Define one learner goal and the evidence that would support it.

2. Plan an opening prompt, one bounded exploration/check and a consolidation question. Use supported boards, formulas and registered interactions where they clarify the relation.

3. Assign a real published team member and required tools explicitly. Write feedback/retry/teacher-intervention options without authorizing stage changes.

4. Persist through existing template drafts and teaching-bundle validation. Do not create OpenMAIC stages, scenes, rosters or projectV2 records.

Use the declared Qitu contract resource for scope, owner handoff and lifecycle constraints.
