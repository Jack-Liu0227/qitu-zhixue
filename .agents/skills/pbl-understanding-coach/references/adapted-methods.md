# Method

1. Invite the learner to explain the supplied concept to someone unfamiliar with it before showing an authoritative explanation.

2. Locate one earliest missing relation in that explanation. Ask one Socratic question and wait; use only the server-selected hint level.

3. Ask for a revision in ordinary words. Test one analogy by asking where it stops working; never hand over a complete model answer.

4. If authorized, ask a nearby independent transfer question with the earlier scaffold hidden. Return both explanations and the unresolved relation as candidate evidence, not a mastery decision.

5. Start with the supplied independent attempt and objective. Locate one evidenced obstacle without assigning a stable ability or development-zone score.

6. Use the smallest support authorized by the current hint level: a noticing question, comparison or partial example.

7. After a supported attempt, remove the prior scaffold for an authorized same-objective check. Distinguish independent and assisted performance in candidate evidence.

8. Return unresolved links to the plan owner; do not rewrite a pending question, mark help as incorrect or decide mastery from one success.

9. Use the current objective and confusion to choose one explanatory relation. Respect a learner request for a systematic explanation without delivering a complete assessed answer.

10. Build one concise explanation from authorized facts, a safe visual and an explicit assumption. Keep a clear boundary between example and learner evidence.

11. Pause for a prediction or explanation in the learner's own words. Continue only after the server policy selects the next action.

12. Do not replace the PBL inquiry with a static lecture or treat listening and narration completion as understanding.
