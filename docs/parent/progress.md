# 学习进展

> Parent 第 2 项（`/parent/progress`）。孩子的成长轨迹与阶段性里程碑的**脱敏投影**。
> 与 [`../student/growth.md`](../student/growth.md) 共享同一份服务端事实数据，
> 但**不是同一个页面**，字段范围不同。

## 1. 内容

- 成长时间线的家长投影（里程碑、阶段摘要、作品、掌握度安全投影）。
- 阶段摘要按家长可见字段渲染，默认不包含原始对话与语音。

## 2. 接口

```http
GET /api/v1/parent/children/:childId/progress   孩子学习进展（授权投影）
GET /api/v1/growth/:childId/growth              成长轨迹（家长授权读法）
```

## 3. 规则

- 每次读取按 `guardian_link` 重做对象级授权，再做**字段投影**。
- 授权失败不能伪装成空数据；不能回退共享 / demo 数据。
- 掌握度只展示安全投影，不展示原始答题内容或完整对话。
- 不展示无意义的排名 / 分数 / 百分位 / 等级。
- 断网时不能把缓存的旧摘要标为最新；**投影过期必须显示时间和状态**。

## 4. 页面状态

| 状态 | 行为 |
|---|---|
| loading | 时间线骨架 |
| empty | 无记录 → 明确「孩子还没有成长记录」 |
| error | 重试 |
| offline | 只读 + 显示数据时间戳 |
| permission-denied | 403 页面 |
