## 发布与操作

1. 使用本仓库正常依赖安装/构建流程生成应用产物，确保新目录和全部图片进入同一版本。UNC 下已有 `node_modules/@qitu/*` 是旧安装快照，不能仅替换业务 JS 后沿用旧包。
2. 正常迁移流程执行 `0043_visual_asset_bindings.sql`。该迁移只建立展示配置表，不改助手模型、课程内容、教学门禁或学生事实，不运行 seed。
3. 部署 API 与相关前端后，在 Admin 外观设置检查默认素材；助手、团队、模板编辑位置可选择素材。旧数据先保留；需要统一时使用批量头像设置或恢复继承。
4. 按真实管理员会话验证保存、刷新回读和四端显示。回滚通过恢复展示选择及旧前端产物；有选择数据时 down migration 明确拒绝直接删表。

没有新增顶级导航；没有调用生产模型提供商、解密凭据或执行生产数据库写入。未来私有上传、在线生图、素材审核发布管理是后续增量。
