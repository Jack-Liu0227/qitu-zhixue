# 固定界面图片与配置持久化补充（2026-10-21）

本轮按用户追加要求，更新各平台侧边栏、页头和显眼的旧装饰图。导航顺序与产品信息架构保持现有合同。

- 新生成侧边栏品牌机器人、默认用户头像两张固定图片。原图、生成工具说明和 SHA-256 收据存于 [fixed-interface/v1](../../../../design-assets/fixed-interface/v1/receipt.json)，运行时使用压缩 PNG；固定图片不增加素材选择入口。工具未暴露具体模型标识，收据如实记录 `not_exposed`。
- 共享导航及教师自定义导航改用图片；Admin 设置菜单、教师快捷入口、学生模板/会话/实验标题、家长成果卡等复用已生成素材。功能按钮继续使用现有可识别操作图形。用户上传的作品与头像继续显示原文件。
- 助手的旧 emoji 与旧外链头像统一展示素材库默认图；已有有效 `asset:` 选择保留，Admin 显式素材绑定优先。
- Admin 助手、团队保存后回读真实对象；批量操作逐项报告失败。团队初始加载不再因切换当前团队重复覆盖编辑结果，GET 不使用浏览器缓存。
- 管家模型选择保存到服务端 `admin.copilot` 用途绑定，保留供应商和模型的完整二元组。刷新后读取服务端默认值；未显式设置时仅使用服务端定义的 `tutor.chat` 回退。目录、保存或回读失败会明确提示并阻止发送。
- 模板编辑保留原课程内容、阶段及 rubric，保存为新草稿版本时移除 bootstrap identity，已有课程版本和项目快照不变。模板页直接读取/保存真实团队版本绑定，并分别显示草稿与 active 状态。

新增 `GET /admin/project-templates/:id/versions/:versionId/bindings`，复用原模板对象治理权限。允许在未归档草稿版本上准备绑定和教学配置；validate/activate 仍要求已发布或试点版本，并保留 Teaching Bundle、角色、模型、技能、知识范围及摘要校验。归档对象拒绝写入，客户端不能放行学习门禁。教学配置保存增加审计事件 `template.binding.bundle.save`，只记录有界对象元数据。

本轮不新增数据库迁移或生产 seed；生产发布与行为验证结果在实际执行后追加。
