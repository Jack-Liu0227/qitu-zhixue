## 1. 目标与交付

建立统一素材库，覆盖助手头像、团队图标、项目模板图标和封面，以及其他具有内容识别意义的展示位。素材按稳定资产 ID 复用，管理员在现有页面选择，四端读取同一份服务端展示配置。

- [生成计划](./01-generation.md)：10 款助手头像、首批数量、视觉规范、提示词、生成批次、质量与成本控制。
- [接入计划](./02-integration.md)：素材库选择器、默认与批量规则、数据合同、权限、存储、四端接线、测试与回滚。
- [全站覆盖清单](./03-site-inventory.md)：覆盖今天/灵感、课程任务、作品成长、知识/技能/工具、教师家长、空态、官网登录及共享 SVG/品牌资产。
- [实施与验证记录](./04-implementation.md)：实际文件、源码范围、测试证据与发布步骤。
- 原有方案入口：[PBL 能力链架构与实施入口](../README.md)。

第一阶段产出 **19 个最终素材**：10 款助手头像 + 3 个团队图标 + 3 个模板主题图标 + 3 张模板主题封面。数量为本计划的制作预算；与实际 Admin 目录对账后可调整，不能据此宣称线上有 19 个业务对象。

素材库中同一头像可被多个助手使用；同一主题图标也可被多个经过管理员明确选择的团队或模板使用。资源复用不改变助手身份、成员关系、课程版本、模型选择或教学授权。

## 2. 当前源码事实与差距

| 对象/展示位 | 已观察事实 | 方案处理 |
| --- | --- | --- |
| 共享机器人 | `packages/ui/assets/assistant/qitu-companion.png` 为 256×256 透明 PNG，已有生成说明；`RobotMascot` 通过静态导入支持各应用 basePath | 作为风格参考和旧版本兼容兜底 |

| 助手选择入口 | Admin 助手详情的“头像”按钮目前轮换 emoji | 替换为共享素材选择弹窗，10 款头像可检索、预览、复用 |

| 家长端 | `ProjectVisual` 使用通用机器人 | 复用授权项目投影中的主题图，不另查未授权模板/团队 |

## 3. 范围与复用原则

| 优先级 | 范围 | 本轮规划数量 | 复用方式 |
| --- | --- | ---: | --- |
| P0 | 助手头像库 | 10 | 任意数量助手复用，默认自动继承，单个/批量选择 |
| P0 | 光学、动能、编程团队图标 | 3 | 不同团队可选同图，不据图标判断团队身份 |
| P0 | 光学、动能、编程模板图标 | 3 | 模板库、灵感空间、项目摘要复用 |
| P0 | 上述三主题封面 | 3 | 现有项目/详情封面槽位复用；没有封面槽位的页面先只换图标 |
| P1 | 内容方向图：物理、编程、工程、数学、艺术、跨学科 | 6 | 今日方向卡、模板分类与内容库兜底 |
| P1 | 活动类别图：提问探究、概念理解、实验观察、表达反思 | 4 | 课程/任务类别展示；不生成完成、通过或解锁事实 |
| P1 | 通用能力图：知识资料、教学技能、工具协作、成长记录 | 4 | 知识库、技能卡、工具卡、成长内容入口 |
| P2 | 空态插图：待探索、暂无项目、暂无作品、无检索结果 | 4 | 五应用的适用空态共用；错误/离线/403 仍有准确状态文案 |
| P2 | 搭档情绪插图：思考、鼓励、庆祝 | 3 | 现有横幅与搭档槽位复用；庆祝由真实状态触发 |

上表为基础 40 个素材的草案。依据用户“全站其他展示位也需覆盖”的补充，再加入作品类别 6、成长记录 4、教师/家长支持 3、官网/登录 2，共 **55 个最终素材的分期预算**，详见全站覆盖清单。首期只落实 P0 的 19 个；P1 为 27 个，P2 为 9 个。阶段/类别、空态图按语义复用，不按 16 个课时逐一制图，也不因页面数增多重复生成。

功能性图标（搜索、删除、返回、开关、成功/错误提示等）沿用清晰的 SVG/现有图标体系。学生/教师/家长个人头像沿用用户身份规则，素材计划不生成可识别个人的肖像。启途 Logo 与第三方引擎品牌标识不纳入重绘清单。

## 4. 执行顺序与验收点

| 步骤 | 工作 | 交付物/退出条件 |
| --- | --- | --- |
| M0 目录对账 | 读取实际 Admin 助手/团队/模板目录；记录已定制头像、校域、模板版本和现有页面槽位 | 对象—用途—素材映射清单；没有生产访问时保留为未核验 |

| M2 首批素材 | 按选定风格补齐 P0，统一导出尺寸、命名、摘要和来源记录 | 19 个最终素材、派生尺寸、资产 manifest、预览目录 |
| M3 素材库基础 | 资产目录、共享组件、服务端默认/覆盖合同；在隔离 fixture 验证 | 所有未知资产和读取失败都有兼容兜底；旧自定义配置保留 |
| M4 Admin 接线 | 助手选择器、继承默认、批量设置、团队/模板选择 | 保存后服务端回读；刷新与新建助手继承验证；明确部分失败 |
| M5 四端接线 | 学生 Tutor/项目/灵感优先，教师/家长授权投影随后 | 同一对象跨端一致；历史发言身份、模板版本、跨学生切换不串图 |
| M6 灰度与交付 | 构建、定向行为测试、桌面/手机截图、灰度发布与回滚演练 | 素材已发布、绑定已保存、页面已显示分别记录证据 |
| M7 扩展 | 按真实缺口补 P1/P2；另行评估后台在线生成 | 复用优先，新增素材有使用位，不积累无人使用的图库 |

以上保留原实施顺序。用户随后授权实施，目前已完成 55 个素材生成及源码接线，实际验证、范围与发布状态见实施记录。
