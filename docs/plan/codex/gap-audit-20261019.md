## 4. 风险排序与关闭条件

1. 真实身份及能力分叉。关闭条件是保存、回读、真实 runtime 请求使用同一权威配置；仅页面勾选和类型检查不足。
2. 历史语义漂移。关闭条件是制品完整 hash、旧包可读、当前文件/助手更改不改变旧项目；停用仍立即拒绝。
3. IMA 越界。关闭条件是四工具逐项项目范围、参数和返回值过滤、限期 provenance、撤权及跨项目反例测试。
4. 课程真源分叉。关闭条件是 validator、bootstrap、API、generator 全部消费实际冻结内容，新 16 节版本与旧 v1 分离。
5. 假学习事实。关闭条件是 pending/判分/实验/action/作品引用由各自 owner 接受，课时结束和 `run` 不直接产生通过事实。

另保留两项独立风险：`TutorService.loadSatisfiedGatesForStudent` 的按学生投影需核对项目/绑定范围；`database/seeds/optics-team-seed.sql` 的 `ON CONFLICT DO UPDATE` 不能当不可变团队版本更新机制。本轮不运行 seed，不通过手工 SQL 修正生产教学事实。
