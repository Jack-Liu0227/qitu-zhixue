# AI 搭档：接待、导师团队与逐课教学重设计

> 状态：新八课专题已实施为受治理试点；真实课堂验收与正式发布尚未完成。

初始核查日期：2026-10-22。实施更新：2026-10-23。**新八课专题已实施并部署为受治理试点，正式课堂验收与发布尚未完成。** 当前结果见 [06 实施与验收记录](./06-implementation-and-acceptance.md)。

初始方案阶段只读取源码及 study-remote 配置。用户随后授权执行，已修改源码、发布新领域 Skill 和团队版本、启用新模板教学绑定并验证实际请求。下方初始核查表及旧源码问题保留为历史基线，不能当作当前新模板状态；此前其他修复仍以各自记录为准。

最新范围与教学架构调整（2026-10-22）：
1. **专题聚焦**：用户明确只考虑**干涉与衍射**，课件和题目可在交互中推荐、改编或自由生成。
2. **零基础初学者假设（Zero-Base Learner Model）**：默认学生没有波动光学与高阶数学基础，严禁直接堆砌公式或要求复杂推导，从日常直观现象出发建构物理模型。
3. **课内“四步闭环”结构**：每课严格按照“① 知识库支撑的通俗理论教学 → ② 动态交互课件演示验证 → ③ 随堂出题与小步检查 → ④ 证据留痕与课时推进”闭环推进。
4. **提示词分阶放行策略**：彻底改变全流程一刀切的防泄露机制。理论讲授与课件演示期放行通俗解释与概念定义；仅在随堂检查期激活严格防泄露守卫（`safety.answer_leak.guard`）与阶梯提示。
5. **动态课件资产化与可迭代复用体系（Courseware Asset Hub）**：动态课件赋予规范化元数据和 `assetId`，实现“优先检索已有标准资产 → 针对卡点按需微调改编（Adapt） → 现场依据知识库全新生成 → 高质量成果归档入库”的持续迭代闭环。当前完整方案见 [05 干涉与衍射 8 课时设计](./05-interference-diffraction-curriculum.md)。下方线上 16 课配置是既有核查事实，03 的综合课表和 04 的散射方案均保留为历史设计，不再作为本次推荐范围。

## 结论

当前问题来自职责、课程合同、运行任务和界面展示没有完全贯通。仅美化开场或修改 `leader` 标签，无法修复整门课的教学闭环。

启途智学助手只承担兴趣交流、意图整理、推荐和确认前引导；**不得成为任何导师团队或运行任务的 leader，也不承担正式课时**。正式项目由领域总导师协调，课时主讲与必要协作导师执行当前教学任务；考核、实践放行、报告批准、课时完成和归档仍由现有服务端 owner 决定。
