## 交付内容

八个新领域分别为种子观察、包装减量、图书角数据、公共导览、历史策展、叙事写作、信息核验和虚拟文创预算。每领域独立团队、三个领域助手与八课时模板，共 24 个助手配置、64 个课时和 32 个理论概念。

课程唯一运行合同为 ProjectTemplateSpec。编写助手只负责生成该合同，不另建课程或学习状态库。实际内容位于 `services/api/src/modules/templates/content/inspiration/`，正式题库在 `packages/ai-client/src/quiz-bank/inspiration.ts`，每概念三道题，共 96 道。答案与解析继续由服务端私有投影保护。

## 通用作品与自主评价

- 新增 `rubric_artifact` 证据档案，对应 `rubric_artifact_validated`。登记的写入方仅为 `works.publish-approved`。
- 门禁所属阶段进入原有注册表；Team Runtime 从注册表读取可识别门禁及阶段，修正其仅从旧四阶段默认表派生而遗漏已注册扩展的路径。
- 新课程使用 `rubric-pbl:v1`，保留 TheoryMastered、四阶段兼容表示及原 owner；原有代码和实验报告档案保留。
- 新课程明确使用 `autonomous-learning.v1`。课时课堂回应采用短活动标准，最终作品采用独立冻结的 `artifactCriteria`，避免把完整作品标准提前施加在课堂讨论上。
- Works 在确切版本自动评价通过且发布后记录通用作品门禁，证据引用包含作品版本 ID；课时完成和最终归档继续核对真实提交、当前批准版本与最终反思。

以上扩展不直接写学生 mastery、项目阶段或成长事实。重复发布使用既有幂等链路；版本变化、跨项目或过期计划仍拒绝。评价故障保留已保存正文，不能假报通过。

## 配置入口与生命周期

新增 `services/api/src/scripts/inspiration-catalog.ts`，由显式有效 Admin 身份运行，复用助手、团队、模板、教学安排和绑定 owner。

```text
--admin-user-id <真实管理员ID>
--inspect
--mode draft|pilot
--projects <可选的已登记slug列表>
--model-provider-id <可选的真实provider ID> --model-id <真实model ID>
```

省略模型 pair 时读取当前 Admin `tutor.chat` 绑定，不按同名裸模型猜测。模型目录不可用、技能未发布/未就绪或资源冲突时拒绝。当前命令只创建本次八类资源，不归档其他模板，不调用历史“两项目目录”命令。

draft 保存模板和教学安排草稿，学生列表不可见。pilot 通过原试点 owner 后再校验和激活绑定，不能提前对未发布/未试点版本执行正式绑定校验。正式发布仍需原 owner 的真实证据，不以隔离测试代替。

配置使用独立 bootstrap identity、稳定的本次资源创建标识与幂等键，回读真实 ID、状态、hash 和修订。相同创建标识下的已有用户改动返回冲突，不覆盖提示词、成员或历史绑定。逐项目记录失败，部分成功不能显示成全部生效。

2026-10-24 20:35 起，以真实启用的 Admin 身份调用原 owner，八项目全部成功：8 个团队、24 个助手、8 个模板首版及 8 个教学安排草稿。模型取当前 Admin 的 `(deepseek, deepseek-flash)`，目录确认可用。再次执行后的资源 ID、状态与 hash 完全一致；命令校验原有 6 个模板版本的内容、状态及绑定保持一致。详细回读保存在[资源证据](./evidence/inspiration-eight-projects-20261024.json)，不包含登录信息或学生学习数据。

## 材料与数据边界

信息核验使用明确标识的虚构公告与转发材料，数据探究使用合成借阅汇总，导览使用虚拟地图，预算全部为教学假设。这些材料可以被分析，不能冒充学生真实观察、校园信息、用户测试或商业结果。

历史策展最小材料包仅转述故宫数字文物库的名称、登记号、类别与年代元信息，来源为[永乐款青花缠枝莲纹压手杯](https://digicol.dpm.org.cn/cultural/detail?id=4c28d94d00c241129903a27752665e9c&page=1&source=1)。核对日期为 2026-10-24，不包含图片授权、制作者或流传故事。材料全文保留在冻结课程内，卡片只显示简短材料说明，不为绕过元数据长度限制而截断来源。

种子和包装项目需要学生跨日记录，模拟日期、教学样本与真实记录分别标记。未接入传感器或外部测量核验，不将文字评价宣称为真实实验核验。新课程首版不授予 IMA 知识库，资料来源与旧项目授权不互相扩展。

## 课时与界面修复

旧 Admin 卡片通过标题/slug 推断排期，导致雷霆战机和八个新课程显示通用文案，光学卡片也显示了不符当前绑定的 45 分钟。现在 Admin 和学生目录复用服务端投影：仅从当前版本实际启用、校验有效且 bundle digest 匹配的教学配置读取课时和时长。当前十项均真实回读为 8 课时、每课 60 分钟；缺少有效配置时显示待配置，不猜测。

模板列表只保留领域、标题、简介、课时、年龄和课程入口，图标/封面/删除收入更多操作。进入课程后只保留一个“教学编排台”：一份课时目录，选中后集中显示当前课时内容、团队和教学者，右侧查看导师方法和成员配置。移除独立发布区块、重复的逐课列表和宏观概览；版本、基本信息、质量检查、JSON 和历史恢复收入高级设置。教学方法使用中文展示名，仍提交 canonical ID。修复父级 Grid 的自动最小轨道造成的列表横向裁切。

产品界面不再使用“草稿”作为课程或编辑状态；当前可选课程显示“已上架”。旧冻结课时中的探索/写作词语仅做视图用词投影，不改写已冻结内容或 digest。编辑后继续创建新课程版本，保存未修改内容不产生新版本。课程内容有未保存修改时禁止保存/启用绑定，避免错版本配置；选择其他课时保留本地编辑。

学生推荐目录只读学生端权威接口，禁止旧目录和 Admin 接口兜底；空列表也是权威结果。请求使用 no-store，页面聚焦、恢复可见、联网和可见时定期刷新，最新请求优先。刷新失败保留可读卡片，权限失败清空旧缓存，断网禁用开始操作。卡片保留简介、实际课时与详情/AI 搭档入口，完整目标和成果保留在详情。
