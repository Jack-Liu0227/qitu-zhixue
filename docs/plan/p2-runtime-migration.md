# P2：参考项目能力迁移与运行时收敛（Planned）

## 目的

在教学闭环稳定后，按试点证据选择 DeepTutor 和 OpenMAIC 的有用能力，避免无边界复制外部平台。

## 迁移优先级

1. DeepTutor：掌握路径、分类型练习、学习上下文、可恢复长任务、结构化教学块。
2. OpenMAIC：PBL 阶段活动、教师/同伴/评审角色、互动课堂块、项目工作区。
3. 后续评估：知识库、插件/MCP、媒体生成、外部 Agent 连接和多渠道通讯。

## 工作项

- 盘点现有 `packages/ai-client`、`model-runtime`、`agent-memory` 与参考能力的重叠合同。
- 优先补齐真实 runtime resolver、tool execution owner、候选投影接受流程和 provider capability 检查。
- 把通用能力做成受限的 server-owned capability，而不是把任意工具暴露给学生 Agent。
- 将长任务、流式输出、工具调用和生成文件纳入同一个可恢复的活动时间线。
- 为模型、工具和媒体能力增加年龄/项目/阶段 allow-list。

## 验收标准

- 每项迁移能力都有对应的学生任务、领域 owner、权限边界和失败行为。
- 不因迁移能力改变现有冻结导航和项目状态机。
- 未成年人数据不进入不必要的外部知识库、日志或第三方 Agent。
- 没有明确试点价值的能力不进入首期默认配置。

## 依赖与交付物

- 依赖：P0/P1 合同和首个试点反馈。
- 交付物：能力差距矩阵、SDK 变更提案、最小实现、迁移测试和废弃/保留清单。
