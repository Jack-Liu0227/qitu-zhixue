# P1：项目模板与课程生成（Planned）

## 目的

把每个项目变成可治理、可复用、可按时长扩展的教学模板，并生成每次课的可执行计划。

## 工作项

- 在 Admin 控制面定义项目模板：适合年龄、先修能力、领域、材料/工具、安全限制、目标、阶段产出和最终作品。
- 为模板绑定 `templateVersion`、默认 4 周配置和可选 8 周配置；模板发布后只允许新版本修改。
- 为每个模块定义知识目标（概念/程序/设计）、先修关系、理论检查和实践证据。
- 生成每次课的结构：导入/复习、理论学习、检查、实践、反思；生成结果必须通过 DAG、时长、目标覆盖和门禁校验。
- 允许教师在激活前编辑草稿；激活后保留学生正在使用的计划快照。
- 首先制作两个 fixture：桌面互动机器人、入门编程小游戏。

## 验收标准

- 同一模板可以生成 4 周/8 周计划，且总时长和目标覆盖可解释。
- 生成失败返回结构化错误，不生成半成品正式计划。
- 计划展示每周目标、单次课任务、阶段产出和验收证据。
- 模板和计划支持 loading、empty、error、permission-denied 状态的管理端界面。

## 依赖与交付物

- 依赖：`p0-domain-contracts`。
- 交付物：模板合同、管理端 CRUD、生成器/校验器、两个示例模板、模板治理文档。
- 参考迁移：借鉴 DeepTutor 的 mastery path 和 practice，借鉴 OpenMAIC 的 PBL phase 与课堂活动。
