# 关于启途智学

> 让好奇心有方向，让每个作品留下成长证据。

启途智学是面向中小学生的项目式 AI 学习平台。平台把 AI 放在学习过程里，把人的思考、选择、实践和复盘放在中心：AI 可以帮助学生提出更好的问题、比较证据、拆解任务和发现盲点，但问题是否值得研究、证据是否可靠、作品是否成立，最终仍由学习者在真实实践中判断和负责。

## 我们相信什么

学习不是把答案搬进记忆，而是把一个问题变成自己的理解和作品。项目式学习提供真实的任务、连续的反馈和可追溯的成果；AI 搭档提供及时的启发、追问和结构化支持；老师和家长提供关系、边界、鼓励和必要的人工判断。三者共同构成“AI 与人共成长”的学习环境。

启途智学不把学生当成被动完成任务的人，也不把 AI 当成替学生完成作品的自动机器。每一步支持都应当让学生更清楚自己在做什么、为什么这样做、下一步如何验证，以及哪些决定需要自己承担。

## 从问题到作品

主页展示的项目式学习路径被实现为四个连续环节：

1. **真实问题与精准提问**：观察生活和学科现象，收敛值得研究的问题和目标作品。
2. **AI 协同探索与验证**：通过提问、资料、比较和证据检查形成可解释的研究判断。
3. **原型、作品与实践**：把想法变成可以运行、展示或被他人理解的作品，记录版本和证据。
4. **多元反馈与成长复盘**：回看选择、方法和结果，形成可追溯的成长记录和下一步方向。

这条路径对应平台中的灵感空间、AI 搭档、学习计划、理论门槛、制作工作台、作品展厅和成长轨迹。正式项目必须经过学生意图确认；理论尚未掌握时，实践阶段不会被服务端解锁。

## 希望培养的能力

启途智学关注能迁移到新问题中的能力：批判性思维、问题定义、研究与证据意识、创造与表达、协作与反馈、反思与自我管理。能力不是页面上的标签，而是由问题、过程、作品和复盘共同留下的证据。

## AI 搭档、老师与家长如何协同

- **学生**拥有问题、作品和学习节奏；可以请求解释、提示、拆解或反馈，但不能把阶段、掌握度或成长记录直接写成结果。
- **AI 搭档**只读取经过授权的上下文，遵守教学动作和项目门禁；它可以委派真实 Team Runtime 任务，结果通过服务端任务、事件和候选投影回传，不以假数据宣称完成。
- **班主任**看到负责学生的最小必要投影，在出现风险、卡顿或需要人工判断时介入；班主任不能直接伪造学生的掌握度或项目阶段。
- **家长**在授权范围内看到脱敏的成长进展、里程碑和消息，不直接读取原始对话、模型凭证或内部 Agent 状态。

## 公开主页提供什么

公开官网由 `apps/auth-portal` 提供，当前正式页面包括：

| 页面            | 信息                                               |
| --------------- | -------------------------------------------------- |
| `/`             | 产品主张、项目式学习摘要、能力摘要、公开作品和入口 |
| `/learning`     | 从问题到作品的项目式学习路径                       |
| `/competencies` | 能力维度和过程性成长说明                           |
| `/showcase`     | 已公开的项目模板和作品展示                         |
| `/about`        | 团队、产品背景和品牌信息                           |
| `/contact`      | 咨询联系和合作线索提交                             |
| `/login`        | 四类角色的统一登录入口                             |

公开内容只读取聚合后的平台数据；咨询提交是唯一公开写入口，必须使用幂等键和服务端字段白名单。任何学生、家长、教师或模型的敏感数据都不应出现在公开页面。
