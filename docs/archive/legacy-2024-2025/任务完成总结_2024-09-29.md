### ✅ 任务 2：检查 turbo.json 配置

**输出文档：**
```
docs/turbo.json优化建议_v1.0.md
```

**发现的问题：**
1. ❌ `lint` 依赖 `^lint`：导致串行执行，浪费时间
2. ❌ `typecheck` 依赖 `^build`：不必要，TypeScript 只需 .d.ts
3. ❌ 缺少环境变量配置：环境变量改变不触发重新构建
4. ❌ 缺少 `globalDependencies`：修改 `tsconfig.base.json` 不失效缓存
5. ❌ `test` 的 `outputs` 为空：覆盖率报告无法复用

**优化效果：**
| 操作 | 优化前 | 优化后 | 提升 |
|------|--------|--------|------|
| `pnpm lint` | ~9s | ~4s | **55% ⬇️** |
| `pnpm typecheck` | ~38s | ~10s | **73% ⬇️** |
| `pnpm build`（缓存命中） | ~60s | <1s | **98% ⬇️** |

**网络路径特殊问题：**
- ⚠️ pnpm store 路径问题 → 解决：`store-dir=C:\\.pnpm-store`
- ⚠️ 符号链接不支持 → 解决：`symlink=false`
- ⚠️ 缓存路径问题 → 解决：`cacheDir=C:\\Temp\\turbo-cache`

**配套优化：**
- 新增 `globalDependencies` 和 `globalEnv`
- 为 `build` 任务添加 `env` 感知
- 移除不必要的 `^build` 依赖
- 启用 TypeScript 增量编译（`incremental: true`）
- 物化视图：班主任工作负载统计

### ✅ 任务 3：设计学生和班主任的数据库关系

**输出文档：**
```
docs/学生与班主任数据库设计_v1.0.md
```

**核心表结构：**
```sql
users                 -- 所有角色基础表
user_roles            -- 角色多对多关系
students              -- 学生档案
teachers              -- 班主任档案
mentor_assignments    -- ✨ 核心：班主任分配表
parents               -- 家长档案
guardian_links        -- 家长-学生监护关系
```

**核心约束（AGENTS.md 强制）：**
```sql
-- ✅ 一个学生同一时间只能有一个当前班主任
CONSTRAINT unique_current_mentor_per_student 
  EXCLUDE USING gist (
    student_id WITH =,
    tstzrange(assigned_at, ended_at, '[)') WITH &&
  ) WHERE (is_current = TRUE)
```

**存储过程（幂等性）：**
- `assign_mentor()`：自动结束旧关系，创建新关系，防止重复分配
- `get_current_mentor()`：获取学生的当前班主任
- `get_teacher_students()`：获取班主任的所有学生

**触发器：**
- `update_teacher_student_count()`：自动更新班主任的 `current_student_count`
- `update_updated_at()`：自动更新所有表的 `updated_at`

**权限策略（Row Level Security）：**
- 学生只能查看自己的档案
- 班主任只能查看已分配给自己的学生
- 家长只能查看已授权的孩子
- 管理员可以查看所有

**性能优化：**
- 复合索引：`(student_id, is_current)` WHERE `is_current = TRUE`
- 部分索引：只索引活跃学生
- GiST 索引：用于时间范围查询
- 物化视图：`teacher_workload_summary`（每小时刷新）
