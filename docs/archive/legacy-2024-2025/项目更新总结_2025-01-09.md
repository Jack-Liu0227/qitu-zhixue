### 2. 核心设计决策

#### DeepTutor 迁移策略

✅ **直接复用**：
- Agent Loop 单一编排引擎
- 三层记忆系统（L1/L2/L3）
- SOUL.md 导师人格定义
- ask_user 结构化提问机制
- 审计日志与证据链

🔧 **改造复用**：
- 精通之路 → 能力地图（增加项目/里程碑）
- 沉浸式阅读 → 理论学习空间（快照化防篡改）
- 活书 → 项目手册（增加安全块）
- 伙伴群组 → AI 导师矩阵（4 个角色）

💡 **理念借鉴**：
- 我的智能体 → 多导师会诊
- 伙伴协作 → 班主任介入工作流

🚫 **暂不迁移**：
- 16 种 IM 渠道（本期仅 Web）
- 101 个 CLI App（限制工具白名单）
- 多 RAG 引擎矩阵（先用单一 RAG）

#### 技术架构关键点

```
学生端 (Next.js 15) ←→ FastAPI Gateway
                            ↓
        ┌───────────────────────────────────┐
        │   AI 搭档核心服务 (Python 3.11+)   │
        │                                     │
        │   ChatOrchestrator                 │
        │      ↓                              │
        │   AgenticChatPipeline              │
        │      ├─ 能力路由（按阶段）         │
        │      ├─ RAG 检索                   │
        │      ├─ 记忆管理 (L1/L2/L3)        │
        │      └─ 人工交接触发器             │
        └───────────────────────────────────┘
                ↓              ↓
        PostgreSQL 15      Redis 7
```

#### AI 导师矩阵

| 导师 | 主要能力 | 路由优先级 |
|---|---|---:|
| 小启（学习主导师） | chat, ask_questions, research, consult | 1 |
| 数学小博士 | solve, quiz, visualize | 2 |
| 项目教练 | task_planning, standup, debug | 2 |
| 评审导师 | assessment, feedback | 3 |

#### 七大核心能力

1. **Ask Questions**：结构化提问卡（兴趣探索）
2. **Quiz**：按知识点类型出题（记忆/程序/概念/设计）
3. **Solve**：分步引导解题（提示等级 1-5）
4. **Research**：子话题分解 + 多源检索
5. **Visualize**：抽象概念可视化
6. **Project Coach**：站会提醒 + 实践指导
7. **Co-Writer**：选区编辑 + 批注模式

#### 三层记忆系统

```
L3: 综合画像
    ├─ 技能掌握度
    ├─ 兴趣方向
    ├─ 学习风格
    └─ 最近关注点
         ↑（每条结论可回溯）
L2: 阶段/项目摘要
    ├─ 结构化事实数组
    └─ 引用的 L1 实体 ID
         ↑
L1: 实体镜像
    ├─ projects (完整快照)
    ├─ tasks
    ├─ conversations
    └─ assets
```

#### 人工介入 5 大触发条件

1. **连续失败**：3 次评估未通过 → 学科教师
2. **情绪信号**：沮丧/抗拒 → 班主任
3. **安全操作**：电路/化学品 → 现场教师（阻塞操作）
4. **AI 低置信度**：模型多次自我修正 → 学科教师
5. **关键节点**：里程碑/答辩 → 班主任评审（阻塞操作）

## 🎯 四个并行开发轨道

### Agent 1: AI 搭档后端核心服务（6-8 周）

**核心职责**：FastAPI + LangGraph 编排引擎

**关键里程碑**：
- Week 2：ChatOrchestrator + 会话管理
- Week 5：Ask Questions + Quiz + Solve 能力
- Week 6：三层记忆 L1/L2/L3
- Week 8：人工介入 + 安全过滤

**技术栈**：
- FastAPI + Uvicorn
- LangChain + LangGraph
- PostgreSQL (asyncpg)
- Redis (aioredis)
- OpenAI API

### Agent 2: 四端问题整改（4-6 周）

**核心职责**：修复 19 个 P0/P1 缺陷

**问题分布**：
- 学生端：9 个（导航/项目状态/成长轨迹/消息中心）
- 家长端：3 个（标签跳转/指标下钻/作品筛选）
- 班主任端：4 个（窄屏适配/问题列表/系统设置移除）
- 管理员端：2 个（搜索输入/AI 配置流程）

**关键改动**：
- 统一项目路由：`/projects/{project_id}?task_id=...`
- 所有筛选/搜索改为 SPA 局部更新
- 新增消息与鼓励中心
- Provider → 模型配置前置校验

### Agent 3: 数据库 Schema（2-3 周）

**核心职责**：PostgreSQL DDL + 存储过程

**表结构设计**：
- 核心业务：15+ 表（用户/项目/任务/绑定关系）
- AI 搭档：7 表（会话/消息/记忆/工单）
- 成长档案：6 表（事件/作品/留言/日历）
- AI 配置：4 表（Provider/模型/绑定/审计）

**关键存储过程**：
- `assign_mentor()` - 幂等分配班主任
- `complete_task()` - 原子完成并推进阶段
- `calculate_project_progress()` - 计算进度
- `trigger_stage_transition()` - 阶段转换触发器

### Agent 4: 学生端前端组件库（4-5 周）

**核心职责**：React 组件 + Storybook 文档

**组件分类**：
- AI 对话：7 个组件（ChatInterface, MessageBubble, HintLevel...）
- 能力交互：6 个（QuizCard, SolveWorkspace, ResearchReport...）
- 项目管理：5 个（ProjectCard, StageProgress, TaskList...）
- 成长档案：5 个（GrowthTimeline, LearningCalendar, EvidenceChain...）

**技术要求**：
- TypeScript 严格模式
- WCAG 2.1 AA 无障碍
- 单元测试覆盖率 > 80%
- Storybook 文档完整

### 3️⃣ 创建 Agent 3 数据库迁移（明天启动）

```bash
# 创建迁移目录
mkdir -p migrations/{data,rollback}

# 创建第一个迁移文件
cat > migrations/001_initial_schema.sql << 'EOF'
-- 启途智学数据库初始化脚本
-- 版本：v1.0
-- 日期：2025-01-09

-- 用户基础表
CREATE TABLE users (
    user_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE,
    phone VARCHAR(20),
    password_hash VARCHAR(255),
    role VARCHAR(20) NOT NULL, -- student/parent/teacher/admin
    status VARCHAR(20) DEFAULT 'active', -- active/suspended/deleted
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 学生档案表
CREATE TABLE students (
    student_id UUID PRIMARY KEY REFERENCES users(user_id),
    real_name VARCHAR(100) NOT NULL,
    nickname VARCHAR(50),
    birth_date DATE,
    grade VARCHAR(20),
    school VARCHAR(255),
    profile_data JSONB DEFAULT '{}',
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 项目模板表
CREATE TABLE project_templates (
    template_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    template_name VARCHAR(255) NOT NULL,
    description TEXT,
    category VARCHAR(100),
    difficulty_level INT CHECK (difficulty_level BETWEEN 1 AND 5),
    estimated_duration_days INT,
    template_data JSONB NOT NULL,
    status VARCHAR(20) DEFAULT 'active',
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 项目阶段定义（统一枚举）
CREATE TYPE project_stage_enum AS ENUM (
    'interest_confirmation',
    'theory_learning',
    'practice_build',
    'work_refinement',
    'showcase_reflection',
    'completed'
);

-- 学生项目表
CREATE TABLE student_projects (
    project_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    student_id UUID NOT NULL REFERENCES students(student_id),
    template_id UUID REFERENCES project_templates(template_id),
    project_name VARCHAR(255) NOT NULL,
    
    lifecycle_status VARCHAR(20) DEFAULT 'draft', -- draft/active/paused/completed/archived
    current_stage project_stage_enum DEFAULT 'interest_confirmation',
    
    progress_percent INT DEFAULT 0 CHECK (progress_percent BETWEEN 0 AND 100),
    progress_version INT DEFAULT 0,
    
    project_data JSONB DEFAULT '{}',
    
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    started_at TIMESTAMPTZ,
    completed_at TIMESTAMPTZ,
    
    INDEX idx_student (student_id),
    INDEX idx_status_stage (lifecycle_status, current_stage)
);

-- 索引
CREATE INDEX idx_users_role ON users(role);
CREATE INDEX idx_users_status ON users(status);
CREATE INDEX idx_students_school ON students(school);
CREATE INDEX idx_projects_template ON student_projects(template_id);

-- 审计触发器
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

CREATE TRIGGER update_users_updated_at BEFORE UPDATE ON users
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_projects_updated_at BEFORE UPDATE ON student_projects
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

COMMENT ON TABLE users IS '用户基础表（学生/家长/教师/管理员）';
COMMENT ON TABLE students IS '学生档案表';
COMMENT ON TABLE project_templates IS '项目模板库';
COMMENT ON TABLE student_projects IS '学生项目实例';
EOF
```
