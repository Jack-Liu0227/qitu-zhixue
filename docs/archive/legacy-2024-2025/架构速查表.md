## 🎯 能力与阶段映射

| 项目阶段 | 主要能力 | 允许能力 | 禁用能力 | 典型场景 |
|---------|---------|---------|---------|---------|

| **作品打磨** | Co-Writer<br>Review | Visualize<br>Chat | - | 学生撰写项目报告<br>AI 选区式修改并补充依据 |

## 🔑 核心 API 速查

### 会话管理

```http
# 创建会话
POST /api/v1/ai-tutor/sessions
Body: {
  "project_id": "uuid",
  "stage": "interest_confirmation",
  "student_id": "uuid"
}
Response: { "session_id": "uuid", "context": {...} }

# 恢复会话（页面刷新后）
GET /api/v1/ai-tutor/sessions/{session_id}
Response: { "session_id": "uuid", "messages": [...], "context": {...} }

# 发送消息
POST /api/v1/ai-tutor/sessions/{session_id}/messages
Body: {
  "content": "老师，这道题我不会",
  "attachments": []
}
Response: {
  "role": "tutor",
  "content": "让我们一起分析...",
  "hint_level": 2,
  "tool_calls": [...]
}

# 流式响应（WebSocket）
WS /api/v1/ai-tutor/sessions/{session_id}/stream
Receive: {
  "type": "chunk",
  "content": "让我们",
  "hint_level": 2
}
```

### 能力执行

```http
# 执行 Quiz 能力
POST /api/v1/ai-tutor/capabilities/quiz/execute
Body: {
  "session_id": "uuid",
  "params": {
    "knowledge_point": "欧姆定律",
    "kp_type": "procedure",
    "difficulty": 3
  }
}
Response: {
  "quiz_id": "uuid",
  "question": "...",
  "type": "multiple_choice",
  "options": [...]
}

# 提交答案
POST /api/v1/ai-tutor/capabilities/quiz/{quiz_id}/submit
Body: { "answer": "A" }
Response: {
  "correct": false,
  "understanding": 60,
  "feedback": "接近了！但是...",
  "next_hint_level": 3
}
```

### 记忆查询

```http
# 获取学生画像
GET /api/v1/ai-tutor/memory/{student_id}/profile

  "skills": { "电路设计": 4, "编程": 3 },
  "interests": ["物联网", "环保"],
  "learning_style": "动手型",
  "recent_focus": ["传感器应用"]

# 回溯证据链

  "conclusion": "电路设计能力强",
  "evidence_chain": [
    { "level": "L3", "content": "..." },
    { "level": "L2", "source_refs": [...] },
    { "level": "L1", "entities": [...] }
  ]

## 🔐 安全与权限

### 工具权限白名单

| 阶段 | 允许工具 | 禁用工具 | 理由 |
|-----|---------|---------|-----|
| 兴趣探索 | web_search_safe, visualize | code_execute, file_system | 探索阶段不需要代码执行 |
| 理论学习 | web_search_safe, quiz, knowledge_base | code_execute | 理论阶段仍不允许代码 |
| 实践构建 | code_execute, file_upload, debug | file_system_access | 开放代码执行但限制文件系统 |
| 作品打磨 | co_writer, web_search_safe | exec_system_command | 写作阶段不允许系统命令 |

**全局禁止**：
- `exec_system_command` - 系统命令执行
- `database_access` - 直接数据库访问
- `credential_access` - 凭证访问
- `network_request` - 任意网络请求

### 数据访问权限

| 角色 | 可访问数据 | 限制 |
|-----|----------|-----|
| 学生 | 自己的全部数据 | - |
| 家长 | 孩子的学习记录、成长档案 | AI 对话默认仅摘要 |
| 班主任 | 管理学生的项目、工单、画像 | 无 AI 系统配置权限 |
| 学科教师 | 被分配工单的学生数据 | 仅临时访问权限 |
| 管理员 | 所有数据 + AI 配置 | 所有操作记录审计日志 |

```
Week 7-8: 所有能力
