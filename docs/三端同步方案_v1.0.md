### Step 1: 修复网络路径的 pnpm 问题

```bash
# 1. 创建 .npmrc 文件（解决 store 和符号链接问题）
cd "\\192.168.137.2\科研资产\Study\qitu-zhixue"

# 创建配置文件
cat > .npmrc << 'EOF'
# 使用本地磁盘作为 store（避免网络路径问题）
store-dir=C:\\.pnpm-store

# 禁用符号链接（网络路径不支持）
symlink=false

# 使用 hard links 代替符号链接
node-linker=hoisted

# 加速安装
prefer-frozen-lockfile=true
EOF

# 2. 清理旧的 node_modules 并重新安装
rm -rf node_modules
rm -rf apps/*/node_modules
rm -rf packages/*/node_modules

pnpm install
```

```bash
# 应该正常显示包列表
```

### Step 3: 设置 Git 分支策略

```bash

# 推送开发分支

# 回到主分支
```

**分支约定：**
```
main（主分支）
  └─ 生产环境代码，只接受来自 develop 的合并

develop（开发分支）
  └─ 日常开发，功能分支合并到这里

feature/*（功能分支）
  └─ 新功能开发，例如 feature/ai-tutor-implementation

bugfix/*（修复分支）
  └─ Bug 修复，例如 bugfix/fix-login-error

hotfix/*（紧急修复分支）
  └─ 生产环境紧急修复，直接从 main 创建
```

### Step 4: 配置自动同步到服务器

#### 方案 A: 使用 GitHub Actions（推荐）

在项目根目录创建 `.github/workflows/deploy.yml`：

```yaml
name: 部署到服务器

on:
  push:
    branches:
      - main        # 推送到 main 时部署到生产环境
      - develop     # 推送到 develop 时部署到测试环境

jobs:
  deploy:
    runs-on: ubuntu-latest
    
    steps:
      - name: 检出代码
        uses: actions/checkout@v4
      
      - name: 设置 Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '22'
      
      - name: 安装 pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 10.10.0
      
      - name: 安装依赖
        run: pnpm install --frozen-lockfile
      
      - name: 构建
        run: pnpm build
      
      - name: 部署到服务器（生产环境）
        if: github.ref == 'refs/heads/main'
        uses: appleboy/scp-action@master
        with:
          host: ${{ secrets.PROD_SERVER_HOST }}
          username: ${{ secrets.PROD_SERVER_USER }}
          key: ${{ secrets.PROD_SERVER_SSH_KEY }}
          source: "."
          target: "/var/www/qitu-zhixue"
          rm: false
      
      - name: 部署到服务器（测试环境）
        if: github.ref == 'refs/heads/develop'
        uses: appleboy/scp-action@master
        with:
          host: ${{ secrets.DEV_SERVER_HOST }}
          username: ${{ secrets.DEV_SERVER_USER }}
          key: ${{ secrets.DEV_SERVER_SSH_KEY }}
          source: "."
          target: "/var/www/qitu-zhixue-dev"
          rm: false
      
      - name: 重启服务（生产环境）
        if: github.ref == 'refs/heads/main'
        uses: appleboy/ssh-action@master
        with:
          host: ${{ secrets.PROD_SERVER_HOST }}
          username: ${{ secrets.PROD_SERVER_USER }}
          key: ${{ secrets.PROD_SERVER_SSH_KEY }}
          script: |
            cd /var/www/qitu-zhixue
            pm2 reload ecosystem.config.js --env production
```

**配置 GitHub Secrets：**
1. 访问：`https://github.com/你的用户名/qitu-zhixue/settings/secrets/actions`
2. 添加以下 Secrets：
   - `PROD_SERVER_HOST`：生产服务器 IP
   - `PROD_SERVER_USER`：SSH 用户名
   - `PROD_SERVER_SSH_KEY`：SSH 私钥
   - `DEV_SERVER_HOST`：测试服务器 IP
   - `DEV_SERVER_USER`：SSH 用户名
   - `DEV_SERVER_SSH_KEY`：SSH 私钥

#### 方案 B: 服务器端 Git Hook（轻量级）

在服务器上设置自动拉取：

```bash
# 1. SSH 到服务器
ssh user@your-server.com

# 2. 克隆仓库
cd /var/www
git clone https://github.com/你的用户名/qitu-zhixue.git

# 3. 创建自动拉取脚本
cat > /var/www/qitu-zhixue/deploy.sh << 'EOF'
#!/bin/bash
set -e

echo "🔄 开始同步代码..."

cd /var/www/qitu-zhixue

# 拉取最新代码
git fetch origin
git reset --hard origin/main

# 安装依赖
echo "📦 安装依赖..."
pnpm install --frozen-lockfile

# 构建
echo "🔨 构建项目..."
pnpm build

# 重启服务
echo "🔄 重启服务..."
pm2 reload ecosystem.config.js --env production

echo "✅ 部署完成！"
EOF

chmod +x /var/www/qitu-zhixue/deploy.sh

# 4. 设置定时任务（每 5 分钟检查一次）
crontab -e

# 添加以下行：
*/5 * * * * cd /var/www/qitu-zhixue && git fetch origin && [ $(git rev-parse HEAD) != $(git rev-parse origin/main) ] && /var/www/qitu-zhixue/deploy.sh >> /var/log/qitu-deploy.log 2>&1
```

#### 方案 C: 使用 Webhook（实时同步）

在服务器上设置 Webhook 监听：

```bash
# 1. 安装 webhook 工具
# Ubuntu/Debian:
sudo apt install webhook

# CentOS/RHEL:
sudo yum install webhook

# 2. 创建 webhook 配置
cat > /etc/webhook/hooks.json << 'EOF'
[
  {
    "id": "qitu-deploy",
    "execute-command": "/var/www/qitu-zhixue/deploy.sh",
    "command-working-directory": "/var/www/qitu-zhixue",
    "pass-arguments-to-command": [
      {
        "source": "payload",
        "name": "ref"
      }
    ],
    "trigger-rule": {
      "match": {
        "type": "payload-hash-sha1",
        "secret": "你的webhook密钥",
        "parameter": {
          "source": "header",
          "name": "X-Hub-Signature"
        }
      }
    }
  }
]
EOF

# 3. 启动 webhook 服务
webhook -hooks /etc/webhook/hooks.json -verbose -port 9000

# 4. 在 GitHub 上配置 Webhook
# 访问：https://github.com/你的用户名/qitu-zhixue/settings/hooks
# Payload URL: http://your-server.com:9000/hooks/qitu-deploy
# Content type: application/json
# Secret: 你的webhook密钥
# 触发事件：Just the push event
```
