# Six-dimension learning profile

The existing personal profile gains a six-dimension observation framework without
changing student navigation: problem discovery, scientific inquiry, logical
modeling, practical creation, collaborative expression and reflection/transfer.

The hexagon remains visible when no assessment is available. Its labels can be
selected to read the dimension definition and evidence requirements. Missing
assessment is displayed as pending observation, not zero or a default score.

The current feature does not establish a new grading workflow. Existing boolean
teacher checks, interests, project counts and mastery facts do not become radar
values. Only an explicitly governed, version-matched assessment with owner-backed
evidence can support future graded points. Old projects never inherit a current
rubric silently.

Real interests, confirmed summaries and recent learning records remain visible
alongside the diagram. Unassigned evidence is not guessed into a dimension. A
pending new analysis does not hide the previously confirmed result. Permanently
deleted source records are not restored or regenerated from fictional evidence.

The page retains read-only authorization, visible-page refresh, keyboard controls,
mobile layout, night theme and clear loading/offline/error/permission states.
