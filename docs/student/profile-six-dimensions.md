# Six-dimension learning profile

The existing personal profile gains a six-dimension observation framework without
changing student navigation: problem discovery, scientific inquiry, logical
modeling, practical creation, collaborative expression and reflection/transfer.

The hexagon remains visible when no assessment is available. Its labels can be
selected to read the dimension definition and evidence requirements. Missing
assessment is displayed as pending observation, not zero or a default score.

The default view is now learning footprints. The explicit `learning-footprints.v1`
policy maps confirmed intent receipts, saved experiment observations, submitted
exercises, saved artifact versions, owned student Tutor turns and saved reflections
to the six corresponding observation axes. The service reads metadata and opaque
references only, never classifies raw text or infers ability. Each axis retains up
to 32 recent unique references and draws at most five records. A clearly labelled
dashed starting illustration is available without evidence. It is not a preset score.

The separate formal-assessment view retains the existing requirements. Boolean
teacher checks, interests and project counts do not become assessment values. Only
an explicitly governed, version-matched assessment with owner-backed evidence can
support graded points. Old projects never inherit a current rubric silently.

Real interests, confirmed summaries and recent learning records remain visible
alongside the diagram. Unassigned evidence is not guessed into a dimension. A
pending new analysis does not hide the previously confirmed result. Permanently
deleted source records are not restored or regenerated from fictional evidence.

The page retains read-only authorization, visible-page refresh, keyboard controls,
mobile layout, night theme and clear loading/offline/error/permission states.

The profile also reads `/students/me/learning-activity` and `/students/me/encouragements`.
Activity uses the same Shanghai natural-week policy as parent and teacher views.
Encouragements are independent communication records, not growth or mastery facts;
revoked guardians are excluded from the student inbox.
