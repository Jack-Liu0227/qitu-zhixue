# 远程知识库一键连接检测

入口为 `/admin/settings/knowledge` 的“远程知识库连接检测”。点击“一键检测远程知识库”检测全部远端连接，包含搜索或引擎筛选隐藏的库以及已停用的库。本地索引库不参与。

## 结果解释

- 缺少认证凭证：知识引擎尚未配置完整凭证。
- 认证/授权被拒绝：上游拒绝凭证或访问权限，可能是凭证失效或权限被撤销，不能直接断定过期。
- 资源不可访问：远端库 ID 无效、资源不存在或无权访问，可进入“配置此库”核对关联。
- 网络连接异常、请求被限流或其他连接异常：认证状态未核实，不显示为认证失效。
- 连接检测通过：只代表该次连接检查通过，不代表所有原文可读，也不授予助手访问权。
- 结果待核验：请求中断，保留原库修订号、请求和幂等键，点击“核验未确认项”只重放未确认请求。
- 未完成检测：管理员会话失效、配置冲突、来源不支持或未发起检测；不等同远端认证失败。

逐库展示检测时间和稳定错误码。服务端检查结果写入既有连接状态和审计，重新打开页面后仍可看到最近结果；批次进度只保留在当前页面会话内。没有最近检查时间的历史 `ready` 状态显示“尚未检测”。

## 权限和配置边界

没有新增接口、数据表或迁移。复用 `GET /api/v1/admin/knowledge/binding-matrix` 获取最新完整目录和库修订号，然后最多并发两个既有 `POST /api/v1/admin/knowledge/bases/:id/check` 请求。仍由服务端执行管理员认证、修订保护、真实适配器调用、幂等和事务审计。IMA 检查包含资源连接及目录读取。

目录不可读或不完整时不发起检测。管理账号权限失败后停止后续排队请求，已发出的请求可能完成。部分失败不阻断其他库结果；请求中断与目录刷新失败均明确提示，不显示为全部通过。检测期间暂停本页引擎编辑、库配置和矩阵写入，绑定草稿保留。检测更新库修订号，旧草稿若遇冲突须重新读取并核对后保存。

检测不更新凭证、资源关联、库启停、助手绑定或项目冻结 grant，不刷新或扩大学生权限。不输出上游异常正文、凭证或文件内容。已停用的引擎不能执行检查，应先在引擎配置中启用；此类拒绝显示“未完成检测”。
