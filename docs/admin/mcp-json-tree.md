# 工具与 MCP JSON 配置树

本次按已确认的知识中心方案恢复原有页头、三个视图、配置目标清单和黑色 JSON 编辑区。导航与授权矩阵保持原入口。

## 目标与编辑

- 全局 JSON 使用现有 `mcpServers`、`knowledgeEngines`、`platformTools` 三分区，由 `GET/PUT /api/v1/admin/platform-config` 持久化。
- 清单增加“知识库”：根行对应 `platformTools.project-knowledge`，内部引擎行对应 `knowledgeEngines[instanceId]`；ima 在该层级中配置。
- 名称选择配置，箭头仅展开子项。查看子工具不替换右侧草稿。知识中心的 `?knowledgeEngine=实例ID` 链接自动选择引擎并展开父节点。
- 新引擎由 provider 和唯一实例 ID 生成关闭状态的草稿；保存后才进入注册配置。配置保存、启用状态与连接预检分别展示。
- 切换目标、离开矩阵、重新读取前，对未保存草稿提供保存、放弃、取消；JSON 预览保持只读。保存继续使用修订冲突校验、幂等键、事务与审计。
- 引擎共享项目检索授权，不建立逐引擎学生聊天权限。助手标签读取真实配置，模型绑定保持原值。

## 子工具参数

管理员专用接口：`GET /api/v1/admin/platform-config/tools/:section/:id`，`section` 仅接受 `mcpServers`、`knowledgeEngines`、`platformTools`。`?refresh=1` 显式刷新目录。

- 知识库搜索和阅读工具直接复用 `KnowledgeRetrievalService.tools()` 的模型运行时定义，不复制 schema。
- ima 从服务端现有连接引用完成 MCP 初始化和分页 `tools/list`，仅显示既有只读白名单内实际返回的工具。目录查询不会执行 `tools/call`；目录有时限、响应大小与游标循环保护。
- 元数据缓存一分钟，并合并同时发起的 ima 查询。刷新失败保留上次成功定义并标记过期；上游异常正文与凭证不返回浏览器。
- 其他现有 MCP 注册表只保存工具 ID，未保存 inputSchema，也没有通用连接适配器。界面可展开全部登记工具；没有可验证定义时明确提示“参数定义暂不可用”，不展示猜测的 query/options。
- LlamaIndex 通过项目搜索/阅读使用索引，没有独立模型工具；其他未登记独立工具的引擎同样明确显示状态。
- 参数面板显示名称、类型、必填、说明与约束，同时完整展示只读 inputSchema（含嵌套属性、组合、引用等）。不远程解析 `$ref`，不执行 schema 中的示例或 HTML。

## 当前边界

顶部“添加 MCP”保留原位置。当前后端只接受已注册服务；新增连接须先在服务器注册，再重新读取。不能把浏览器本地生成的假工具和模拟延迟当作已接入。知识引擎可通过知识库内入口添加。

本次不变更知识构建、学生对话路由、模型配置和教学门禁，不需要数据库迁移。回滚只需恢复 API 与 admin 的服务发布目录；本次元数据接口没有数据写入。
