# 光学与雷霆战机自主学习全流程线上验收

状态：已完成。本轮两个新建合成项目均完成 8/8 课时并由服务端归档，使用当前 `autonomous-learning.v1` 自动评价；未调用教师批准接口。保留所有未达标与修订历史，不把旧项目成功作为本轮验收。

## 验收约束

- 从学生端灵感空间创建项目，依次完成当前课时教学、课件、检查、实践和反思，再由服务端确认课时完成。
- 全程不使用教师批准接口，不直接写 mastery、门禁、阶段或质量结论。自动评价使用 Admin 配置的真实模型；不达标则保留反馈并修订合成学习回应。
- 课件必须实际渲染 SVG/公式并可重播；游戏需实际运行窗口并保留源码摘要与测试回执。
- 线上使用合成演示账号，已有掌握事实不清空；首次学习、错误补救与权限边界另在隔离 owner 测试覆盖，明确区分这些证据。
- 两个项目完成后重启 study-remote 全部已启用应用服务，重新登录核对 16 个课时记录、课件、目录与服务健康。
