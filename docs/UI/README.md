## 如何理解截图

- `*-desktop.png`：1440×1000 桌面视口下的文档长截图；固定高度工作区可能只有当前屏幕。
- `*-mobile.png`：390×844 手机宽度下的截图。属于 Chromium 视口模拟，不代表 iOS/Android 真机验收。
- `*-section-N.png`：官网实际滚动到第 N 屏后的截图。官网有滚动揭示动画，长截图会遗漏视口外尚未展开的卡片；**官网内容完整性以 section 截图为准**。
- `*-scroll-P-N.png`：第 P 个内部滚动区的第 N 个补充屏幕。管理端和教师详情存在内部滚动，长截图不能代替这些分段。
- `optics-preview-*`：对话滚动区中固定光学模型预览的原生分屏截图，不是全页或正式实验验收。
- 灰块为账号、输入字段、部分身份/表格信息的遮蔽；Tutor 对话区留白为原始对话脱敏。**这些遮蔽不属于 UI 问题**。显式命名为“演示”的公共样例标签可保留，未导出原始会话文本。

本次覆盖当前可访问的主导航、设置目录和已发现的代表性详情。没有穷举所有数据对象、所有弹窗组合和所有权限角色；无现存对象或需要写入才能产生的状态在报告中标为未验证。错误与兼容跳转也作为实际 UI 结果保存。

## 事实与操作边界

线上截图、当前源码、后台配置和真实写入成功是不同事实层。本报告首先描述线上可见行为；源码仅用于定位可能的修复入口，不能据此断言已部署版本或后台功能完整性。

通过页面提供的演示入口登录四个角色，浏览页面、切换展示状态，并检查登录离线和未登录恢复。打开 Tutor 会触发产品自身的自动开场行为；打开动态课件会呈现模型预览。本次未主动提交学生答案、实验预测、观测、作品、家长反馈或后台配置，未批准掌握度、推进项目或执行管理批量写入。

仅新增 `docs/UI` 审查产物，没有修改业务代码、冻结导航、权限或教学门禁。仓库中原有修改已保留，见 [工作区基线](06-evidence/workspace-before.txt)。
