# 覆盖与验证说明

## 审查环境与方法

- 目标：http://122.51.130.204/。
- 审查日期：2026-10-21，截图发生在北京时间凌晨；原始时间戳使用 UTC ISO，因此 JSON 中日期部分可能为 2026-10-20。
- 使用 Playwright Chromium 进行实际导航、演示登录、视口调整、DOM 检查和截图。agent-browser CLI 的 batch 在本环境未正确接收参数/标准输入，因此切换到可用的 Playwright 工具。
- 主视口：1440×1000、390×844；不是设备性能或真机测试。
- 页面到达后等待加载和短暂稳定，再截图；部分页面没有标准 busy 状态。`settleMs` 包含自动化等待，不能作为 FCP、LCP 或响应时间报告。
- 官网使用真实滚动分段捕获动画后的内容；管理设置、教师详情补拍内部滚动。元素位于视口外不自动判定为布局错误，局部二维滚动另行人工判断。
- 中途指针/键盘自动化点击未稳定触发事件，部分展示操作通过 DOM click 完成。该现象未列为产品缺陷，也没有据此宣称鼠标/键盘操作全部通过。

## 隐私与证据解释

截图遮蔽邮箱/密码字段、部分账号/身份/表格内容；Tutor 原始对话内容不进入图库。显式演示角色标签及授权界面的汇总数字用于描述 UI，不代表已验证的学习成果。输入与 JSON 编辑区的灰块不是渲染缺失。

未将 cookie、token、认证状态文件、密码、完整网络响应、原始未成年人对话或语音写入 docs/UI。浏览器记录中的实际项目/模板 UUID 已替换为 `:objectId`；对象占位符用于说明路由结构，不可直接发起请求。

## 工作区与验证边界

开始前检查了 git status 和目标目录 diff；`docs/UI` 原为空目录。原有修改完整记录在 [workspace-before.txt](workspace-before.txt)，主要涉及管家、技能中心、contracts、runtime、platform-registry 和既有实施文档，另有用户未跟踪脚本与文件。

本次只增加 `docs/UI`，没有改动这些业务文件。现有修改的业务正确性没有被本次视觉审查认证；本次对自己的文档、图片、路径与图库单独验证。没有为文档/截图任务运行全量业务构建或声称类型检查通过。

文件完整性由 [build-gallery.py](build-gallery.py)检查 PNG 签名/尺寸并生成 SHA-256 清单。另执行新文档本地链接检查、图库浏览器检查、全仓文档校验，并在 [validation-results.txt](validation-results.txt)记录结果及既有问题。
