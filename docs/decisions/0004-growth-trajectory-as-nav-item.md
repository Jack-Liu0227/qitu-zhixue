# ADR 0004：成长轨迹提升为学生端一级导航项

- 状态：**Accepted**
- 日期：2026-09-26
- 范围：学生端导航与信息架构（`apps/student-center/app/student-shell.tsx`、`app/growth/`）
- 关联：产品文档 0.4「不改变的产品框架」、4.1 路由、4.7 成长轨迹、ADR 0002（领域边界与单一写入者）

## 背景

产品文档 0.4 把学生端导航冻结为五项：今天、灵感空间、AI 导师、我的项目、作品展厅；
`AGENTS.md` 同时写明「不改变已经冻结的产品导航和 UI 信息架构，除非先更新产品文档并通过评审」。

成长轨迹此前按 0.4 的实现方式存在：它是一个**有独立路由**（`/student/growth`）
但**不在导航里**的页面，从「今天」和「我的项目」侧向进入。

2026-09-26 产品要求成长轨迹成为「与 AI 搭档同级的独立界面」，理由是：
成长档案是学生会**主动回看**的目的地，而不是某个页面的附属明细视图；
侧向入口使它事实上不可发现。

## 决定

1. 学生端导航由五项扩为**六项**，新增「成长轨迹」。
2. 新增项**追加在末尾**，原有五项的名称与相对顺序**完全不变**。
3. `/student/growth` 成为一级目的地：该页**不得假设**自己是被带着
   `projectId` 进入的，必须能独立渲染完整时间线。
   `?projectId=` / `?type=` 继续支持，用于从今天页与项目页的深链预筛选。
4. 产品文档 0.4 与 4.1 已同步更新，并新增 4.7 描述该页面的功能、规则与验收标准。

## 影响

| 面 | 影响 |
|---|---|
| 学生端 | 导航多一项；移动端/窄屏需容纳第 6 项（窄屏已有收起按钮） |
| 家长端 | 无变化。家长看的是**同一份事实数据的脱敏投影**，不是同一个页面 |
| 后端 | 无接口变化。`/students/me/growth`、`/parent/children/:childId/growth` 已存在 |
| 信息架构 | 冻结 IA 发生一次受控变更，已按 `AGENTS.md` 要求**先改文档** |

## 没有做的事（刻意的）

- 没有调整原有五项的顺序。把「成长轨迹」插在中间会让冻结序列发生变化，
  收益不抵风险。
- 没有把导航项文案与产品文档统一。文档写「AI 导师」，代码写「AI 搭档」——
  这是**先前就存在**的不一致，不在本 ADR 范围内，另开Issue 处理。
- 没有实现「AI 总结与建议」的接入（RAG / `growth.summarize` 用途模型）。
  入口与契约位置先保留，接法待定稿。

## 未验证

没有浏览器环境，因此「六项导航在窄屏下不换行、不遮挡」**未经视觉验证**。
`navCollapsed` 起手状态与 hydration 一致性由既有实现保证，未因本次变更改动。
