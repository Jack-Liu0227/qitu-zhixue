## 2. 发布检查需要区分的事实

建议在现有模板治理页面显示可核查状态，不新增导航：

- 结构通过：schema、课时顺序、目标和引用有效。
- 教学合同齐备：每课开场、角色、活动、完成规则、必要能力与资料范围齐备。
- 运行条件可用：指定模型、所需知识连接与工具执行器可用，检查有时间和范围。
- 进度链路验证：真实证据可被接受、完成本课并恢复到下一课。
- 课堂验收：规定的理论—实践—产物—反思流程已验收。

当前 binding 的 `configurationReady=true` 不应被解释成上述所有状态。检查结果必须注明源码、保存、发布、启用、真实请求或课堂验收的事实层。

## 3. 需要提前处理的版本风险

### Skill 修订会影响旧 pin

现有运行时对 Skill 的 canonical ID、version 和 digest 做固定匹配。直接覆盖已发布的 `tutor-guided-learning` 内容，可能导致旧项目因 digest 不符而不可用。

实施前应确认现有技能 owner 能否按冻结 pin 读取已审核历史内容。若不支持，先在该 owner 内补归档与读取能力，或确定明确的迁移窗口与恢复流程；不能假定已经具备，也不能伪造旧摘要或复制一个版本后缀 Skill 绕过审查。每个 canonical ID 继续保持唯一源码职责。

新教学策略也应有版本边界。旧项目缺少新策略时采取明确兼容规则，不把缺字段默认解释成已批准扩大披露或工具范围。

### 冻结项目迁移

保留旧项目进度的迁移需要对实际 session、目标、题目、证据、作品版本和新完成规则逐项映射。原 owner 若只支持修复缺失快照，不能直接用其修复入口替换合法冻结项目。应先评审迁移 owner 能力和权限，再做范围明确的迁移。

### 材料与实践范围

知识权限仍为冻结 grant、Admin 当前授权、助手工具和对象范围的交集。新知识库不自动进入旧项目。实际实验需要教师安全审核，仿真仍只使用注册模型、版本和参数域。

## 4. 人工验收场景

| 编号 | 操作或条件 | 应看到的结果 |
|---|---|---|
| A01 | 从模板进入，尚未确认 | 固定项目介绍、真实接管角色和课程预览；无正式项目和完成率 |
| A02 | 重复点击同一次立项确认 | 一个正式项目、一份冻结绑定；模板再进入能明确选择继续或重新开展 |
| A03 | 正式第 1 课 | 主讲职责匹配观察教学，有明确目标、活动与完成条件；不由只负责交接的角色长期主讲 |
| A04 | 询问定义、原理或教学示例 | 直接讲清允许的知识；不因出现“结论是”被替换成反问 |
| A05 | 当前题未提交时求助 | 保留 pending 题，允许相近示例与概念帮助，不判错、不提前返回私有答案 |
| A06 | 已提交练习后请求解析 | 依据 owner 回执按策略显示答案与解析，不继续一律拒绝 |
| A07 | 同一课给出不同观察或错误原因 | 生成贴合当前活动的不同课件或补救；目标、主讲及证据范围保持一致 |
| A08 | 连续翻板书或聊天 | 只改变图示与对话；不会因页数或轮数完成课时 |
| A09 | 提交满足本课规则的证据 | 保存、评价和完成 owner 依次回执；完成课数、当前课和主讲一起更新 |
| A10 | 缺少完成规则、质量评价或证据 | 显示准确缺口；不能“继续”绕过；模板发布检查也应阻止未齐备课程 |
| A11 | 刷新、断网、重试、删聊天后重新进入 | 回到当前未完成活动；不重复出题、保存证据或生成第二个正式项目 |
| A12 | 两个项目和两个不同 revision 快速切换 | 旧响应不覆盖当前对象；同名门禁和旧证据不串用 |
| A13 | 请求提前进入实践 | 明确缺少理论或安全条件；服务端拒绝越界工具动作 |
| A14 | 满足门禁后使用单缝／细雾仿真 | 真实 action 回执、参数校验、observations 回读；区分模拟与真实测量 |
| A15 | 报告提交、批准、答辩和反思 | 对应同一不可变作品版本；课时完成、报告通过和归档分别有 owner 事实 |
| A16 | 新合同发布、撤权或 Skill 修订 | 新项目正确冻结；旧项目按批准的兼容／迁移规则工作，撤权及时收紧 |
| A17 | 后台规划任务成功或失败 | 显示实际协作状态；“规划建议已生成”不冒充本课或项目阶段完成 |

## 5. 验证方式与禁止的替代

行为测试调用真实 owner 合同，覆盖权限、对象范围、幂等、失败与恢复。浏览器检查覆盖实际课时切换、长讲解、板书分步、手机、夜间和断网状态。

真实课堂验收先选一个可完成的理论课，包含概念讲解、检查、错误补救和有效证据；再测试满足门禁的注册实践课；最后测试报告、答辩和归档。以正式证据与回执为准，不用 SQL/Node 注入 mastery、TheoryMastered 或完成记录制造成功。

本轮没有实施变更，也没有执行完整课堂测试。已执行的是线上配置只读核查及两个文本校验纯函数用例。既往 59 项测试和板书回归属于上轮工作，不能记作本稿新方案已通过验收。
