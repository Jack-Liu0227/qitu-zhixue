# 课时教学修复实施记录

用户已授权按审查问题修改代码，所有修改在 `main` 完成。此前的 01–04 文档保留为问题来源；当前实施状态以本记录为准。

## 已接入的行为

- AI 搭档右侧以真实课表、已完成课数和当前活动展示进度，取消四阶段树作为学生课程主轴。四阶段继续承担内部治理和实践门禁。
- 正式项目开场引用当前冻结课时、当前导师和活动指导，不再插入固定四阶段白板。后续课件由模型消费实际课时合同提出候选，服务端验证后展示。
- 普通教学允许概念、公式、结论和独立示例，不再强制每条回复以问句结束，也不因“结论是”三个字删除解释。普通对话不再自动攀升整段会话的提示阶梯。
- 待答题的题干和公开选项可进入模型上下文；私有答案、正确选项标识和解析仅供服务端输出检查。待答题存在时禁止用任意白板、公式或另一个活动替换题目。新生成题目仍只下发公开块，叙述不重复答案。提交后的反馈继续由考核 owner 决定。
- 新增 `lesson-guided.v1` 模板策略，以及独立的 `optics-16x60-v5-guided` 排期。每课显式声明授课助手、canonical Skill、活动指导、证据类型和质量评价规则。正式课程保留 16 课，课程前意图确认不重复计入正式第 2 课。
- 教学包编译器和 Admin 编排台支持新策略下的逐课授课助手，阶段协调人不再强制覆盖课时授课人。旧模板保留原路由校验。
- 新策略运行时只加载本课要求的已授权 Skill。缺少所需技能会明确拒绝；新增授权不扩大旧项目。没有修改既有 Skill 包、冻结 pin 或历史 hash。
- 活动位置由现有作品/学习证据回执、质量评价和正式掌握度投影，无新增数据库或第二套状态机。学习提交携带稳定活动标识；服务端拒绝跨项目、跨版本、跨课和跳活动提交。幂等重试保留原回执。
- 未评价内容、翻页和聊天次数不完成活动。最终反思活动要求真正的反思来源，普通回应不能替代。课时完成仍独立调用既有 owner，理论门禁、报告审核和归档保留原责任方。
- Admin 绑定回读补充课时合同、逐课技能声明和知识范围的就绪信息；绑定有效不再被界面当作课时规则已完整。
- 团队后台任务完成文案改为“规划建议已生成”，避免误认为学生阶段已完成。治理门禁的展示查询增加项目范围。

## 配置和上线步骤

这些是可执行代码与新课程合同，尚不代表线上配置已经发布或真实模型课堂已经验收。

1. 在 Admin 核对实际助手 ID，按 `OPTICS_GUIDED_ROLE_REQUIREMENTS` 补齐每位授课导师需要的 Skill 和工具，保留其他现有绑定。意图接待助手不承担正式课时。使用自建团队时，应在新模板版本显式配置真实 `teamId` 和 `leadAssistantId`。
2. 为实际授课成员和新项目教学包选择已批准的真实知识库及 IMA 只读工具。不得用模板标题推断授权，不得填写虚构知识库 ID；无授权时保持拒绝并提示资料未核验。
3. 发布新的不可变团队版本。通过 Admin 新建 v5 课程版本并准备、校验、激活教学包；或对源码声明的内置团队使用现有 bootstrap 的 `--guided-lessons` 参数，并传入真实团队版本和经过核对的教学包文件。
4. bootstrap 只走现有治理服务进入试点与绑定，不制造课程发布验收证据。正式发布仍通过原 owner 的证据门。
5. 新确认项目冻结新合同。历史有效项目不在读时换绑，不改写快照；历史课程缺少完成规则时，应显式开始新版课程，或另行走经过审核的迁移。缺失快照恢复接口不能伪装为有效项目升级。

第 9–10 课涉及的真实装置仍须教师安全审核；本次没有新增光具座或透镜实验执行工具。注册模拟仍只有单缝衍射和封闭细雾室散射。
