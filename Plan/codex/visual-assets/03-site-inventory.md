# 全站素材库覆盖清单

> 状态：planned · 用户补充要求：除助手、团队、模板外，检查所有适合素材库的地方。以下区分现有展示位、可复用素材与新增制作建议；不把源码/fixture 存在当作线上启用。

## 1. 统一素材库的分类

建议按使用方式分为：头像、实体标识、主题/方向图、封面、教学活动图、成长标记、插画、文件/功能图标、品牌标识。选择器根据当前槽位展示适用素材，而不是给每个页面一套独立库。

- **Image 2 生成库**：需要品牌风格的头像、主题图、封面、插画、较大的成长标记。
- **共享矢量图标库**：按钮、导航、状态、文件类型、细小指标等，需要精准轮廓和可调颜色。
- **已有品牌资产库**：启途 Logo、IMA/其他知识引擎及供应商品牌，保留正式来源。

三类共用来源登记、用途分类与渲染规范；功能/品牌图标默认由系统映射，不允许普通管理员通过选图改变导航语义。素材库统一管理不意味着所有图片都要重新生成。

## 2. 展示位全清单

| 区域 | 需要的素材 | 源码观察/入口 | 处理方式 |
| --- | --- | --- | --- |

| 知识库与资料 | 知识库主题图、资料夹、文件类型图 | `KnowledgeLibrary`、`LibraryDetail`、`PdfDocumentPreview` | P1 资料图 + SVG 文件图；逐库可选主题，不为每份文档生图 |
| 技能中心 | 技能类别图、通用技能图 | Admin skills 目前使用书本 emoji | 复用知识/教学活动/技能图；不为每个 Skill 单独制作 |
| 工具、MCP、插件 | 工具/协作/插件类别图 | Admin tools、plugins、知识引擎组件 | 类别图复用；外部品牌优先现有素材，系统图用 SVG |
| 模型接入 | 提供商/模型类型标识 | Admin model-providers、助手模型选择 | 正式品牌与通用 SVG；不生成看似官方的替代 Logo |
| 教师工作台 | 支持学生、协作反馈插画，项目类别图 | dashboard、issues、attention-students | 补支持插画，复用项目库；真人头像保留首字/账号来源 |
| 家长首页/周报/进展 | 项目图、成长/支持插画、总结类别图 | `ProjectVisual`、`ParentHomePage`、ParentGrowthPage | 复用授权项目与成长图；补家校协作插画，KPI 用精确图标 |
| 消息与反馈 | 通知类别/发件角色图、无消息状态 | 家长 messages、教师 issues、通知投影 | 优先复用头像/协作图；紧急、未读、成功等状态用文字+SVG |
| 全站空态 | 待探索、暂无项目、暂无作品、无检索结果 | `packages/ui/src/states.tsx`、GrowthStateViews 等 | P2 4 张；其他相近空态复用，不把错误页画成“暂无数据” |
| 搭档情绪 | 思考、鼓励、庆祝 | 共享 `RobotMascot` 和各端横幅/空态 | P2 3 张；同一动作多页复用，动作不冒充教学结论 |
| 官网与登录 | 品牌主题插画、人与 AI 协作插画 | auth-portal home、login；已有 Logo 与动态场景 | 补 2 张可复用插画作为候选，按现有槽位接入；保留动态讲解能力 |
| 账号/设备/偏好 | 默认身份、设备类别、主题图标 | 各端账号与学生设备管理、偏好设置 | 复用抽象身份/SVG；不将 AI 助手头像自动设给真人账号 |
| 导航/按钮/状态/数据指标 | 搜索、筛选、返回、删除、成功/失败/断网等 | 四端 shell、Admin 设置导航、共享 states/primitives | 纳入共享图标规范，沿用或整理 SVG；不依赖栅格生图表达精确状态 |
| 实验仿真/公式/流程图 | 装饰性主题图与独立交互图形 | Tutor Mermaid/KaTeX/Board/光学仿真 | 装饰图可复用，数值/光路/条纹/流程由真实模型或结构化内容渲染 |

上述是跨应用的用途清单。实施 M0 时还需形成逐槽位台账：页面/组件、现用素材、asset slot、内容 owner、来源、scope、默认规则、是否已有真实缩略图、接入状态。未来新增页面遵守同一台账与组件规范。

所有新图必须先有使用位或明确的系统默认用途。覆盖更多页面主要靠复用与统一选择，不按页面数量线性增加素材。资产清单最终以 M0 逐槽位对账和样图评审结果冻结。
