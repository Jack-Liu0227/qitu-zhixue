# 自主学习评价与教师只读

2026-10-24 产品决策：学生学习、课时完成、作品评价与项目归档均不得等待教师处理。教师只读已分配学生的记录、评价结果和问题；不能评价放行、批准作品或改变阶段。

平台策略 `autonomous-learning.v1` 显式替代历史模板的 `current_teacher` 执行角色。冻结目标、活动、质量标准、项目绑定和内容 hash 保留；已有课时完成记录保留。新评价以策略版本、课时范围、正文版本和内容摘要为身份，不把历史人工批准冒充自动评价。旧项目未评价的证据可由学生重新触发自动评价。

学生提交 → Works 保存证据 → Admin 模型网关生成逐项评价候选 → Works 校验候选与确切版本并保存评价 → Learning Plan 判断活动/课时条件 → Projects 同步阶段。理论掌握仍由 Mastery/正式考核判定；缺少证据需补充，评价故障可重试，不伪造通过。

模型用途为 `learning.evaluate`，通过既有 Admin 用途策略显式回退到 `tutor.chat`，客户端不可选模型。模型无工具、无状态写权限；仅向模型提供本课目标、冻结标准和经对象授权的有界证据。审计存策略/版本/模型/摘要，不复制学生正文。

权限与错误：教师旧写入口返回 `TEACHER_LEARNING_READ_ONLY`；学生仅可触发本人当前课的评价，不可提交判定字段；`LESSON_EVALUATION_UNAVAILABLE` 可重试，正文已保存；版本变化、异项目或旧计划拒绝。作品发布须有当前确切版本的服务端评价，最终反思与归档仍核对 owner 回执。

本变更不自动部署；本地测试、生产启用与真实模型效果须分别记录。验收应包括无教师/更换教师、错误答案补救、模型故障重试、并发与幂等、作品修订使旧评价失效、首课至末课完成，以及教师只读权限。

## 学生如何从首课推进到末课

1. 打开项目中的当前课时，按服务端返回的当前活动学习课件、完成正式检查或保存模拟观察。
2. 需要表达或作品时，在“本课记录与评价”保存自己的回答。聊天求助仍不等于正式作答或已经保存的活动证据。
3. 保存后触发自动评价；未达标按反馈修改，服务故障可点“重试自动评价”，不必重复创建学习记录或等待教师。
4. 课时条件满足后提交证据申请完成，服务端确认并返回下一课。作品评价通过后发布，再提交最终反思，由既有 owner 核对并归档。

## 兼容与边界

- 旧版课时没有独立质量标准时，从冻结课时目标和证据要求派生评价条目，不改写历史模板。未绑定确切课时的独立作品无法自动发布，返回 `ARTIFACT_EVALUATION_SCOPE_REQUIRED`，须通过课时入口提交。
- 当前评价读取本次提交正文或保存的模拟观察文本；不会执行学生代码，也未把关联文件下载、真实试玩或外部测量核验伪装成已完成。真实运行门禁仍须由其专属证据服务满足。
- 理论掌握、正式考核、安全与对象权限条件保留。自主流程使用已注册低风险模拟；现实实验的安全审核不能作为每课通用前置条件，也不能被文本评价绕过。
- 教师学习审批与干预写接口关闭，当前分配关系仅用于读取授权。家校反馈通信保留，不参与学习完成条件。
- 本轮没有执行部署、重启、生产数据修补或真实模型评测。共享工作区有其他并发修改及提交，本记录仅说明本次自主学习改动，不将其他任务的提交/部署记为本轮成果。
