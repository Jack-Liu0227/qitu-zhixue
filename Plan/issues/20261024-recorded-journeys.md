## R00：验收边界

线上未找到正常受治理的新合成学生开户入口。本轮使用 `student-demo`，通过 UI 确认并创建新项目。该学生已有历史正式掌握证据，**新项目不等于零掌握度新学生**：部分正式 check 被已有证据满足，雷霆项目早期已有实践权限。本轮不能单独证明学生第一次从零获得 TheoryMastered 的生产全路径。

所有学习写入通过可见 UI；只读 API 核对活动、回执和历史。没有生产 SQL 造数、掌握度注入或直接调用完成接口冒充学生操作。隔离完整课程测试使用受控评分和可丢弃内存 fixture，证明 owner 状态与错误分支，不冒充真实模型和生产初学者验收。

雷霆实践确实在本机运行 Pygame 并录屏，提交完整源码、测试输入与实际结果；代码与操作由验收人员协助完成。它证明后续作品链可操作，不能证明零基础学生单凭目前站内讲解就能独立编程。平台目前没有站内 Python 执行器。认证文件和无关学生数据不进入共享证据。
