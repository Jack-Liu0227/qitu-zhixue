# 已保存的动态光学实验恢复可见

状态：已修复并部署到 study-remote。用户反馈“从波的传播，看见条纹”的动态演示消失。

## 原因与复现

服务端仍保存 5 个不同课时的光学实验实例。前一轮减少重复卡片时，渲染器误用只读状态控制展开：`open={!readOnlyReason}`。一旦完成当前活动、切换课时或项目归档，所有历史实验默认折叠，只剩一行标题。

前一轮回放脚本先主动展开折叠框，再验证动画，遗漏了学生首次进入页面能否直接看到动画。此次增加不主动展开的线上回归；修复前实际结果是保存 5 个、默认展开 0 个，断言失败。

## 修复

- 已保存的 v2 动态实验在原消息中默认展开。只读状态继续约束提交，不再隐藏图像和交互。
- 对话内“已保存动态实验”按真实实例和课时列出定位按钮，点击展开并定位原卡片，不额外复制仿真。
- 同一实例重复引用仍去重；不同课时实例保留各自参数、观察和活动归属。
- 既有视觉与对话回归增加首次加载默认展开断言，移除测试替用户展开实验的步骤。

本次只改学生端展示和浏览器验证，不新增课程权限、不调用实验写入、不更改 TheoryMastered、掌握度或既有观察。工作区同时存在 Admin、模板目录、家长端和工作台修改，均不回滚、不纳入本次定向源码同步。

## 验证

生产合成项目：`proj-331436f4-6e93-4736-9c54-12b604241ab4`。

修复前：服务端保存 5 个动态实验，默认展开 0 个。修复后：5 个均在首次加载时展开，刷新仍可见；手动折叠后，按课时入口能重新展开并定位原卡片，连续重播不增加实例、不写学习证据。

学生端生产构建及类型检查通过，发布版本 `EwXUbpm5GUmzH147ivsSk`。已重启学生端及其配套服务，其他服务与数据保持原样。

发布后真实浏览器验证通过：动画实际运动、暂停/继续、参数响应、连续演示、全屏、390px 移动端适配；两个既有项目共 29 份板书逐页渲染并重播，12 个后续思考页保留前图。浏览器无运行错误，回看/重播没有产生 API 写入。

第一次发布被并发源码校验拦住：`TutorPage.tsx` 与 `useTutorSession.ts` 被另一项任务同步了探索入口延迟创建更新。核对与本地已知改动一致后保留，并重新构建，再通过源码一致性校验发布。新增测试最初误用图形的可访问名称，已更正为实际的“波的传播与屏上条纹”，没有修改产品标签来迁就测试。
