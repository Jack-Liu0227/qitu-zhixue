# 团队直接删除与模板绑定可见性

## 行为

团队列表与详情允许管理员删除当前团队配置及成员关联。模板、模板版本、教学绑定内的团队快照和项目绑定快照保留原值；已有课程继续使用已冻结配置。删除不等于停用课程或撤销助手授权，后续编排新教学配置需要重新选择现存团队。

团队详情在现有页面内展示关联模板名称、模板及版本状态、教学绑定状态和引用项目数量，提供定位到对应模板版本的入口。关系只根据模板版本的 `linkedTeamId` 与绑定内实际 `teamSnapshots[*].teamId` 计算，不按名称或 ID 前缀推测。仅返回项目计数，不展示学生身份或学习内容。

删除前读取关联摘要和团队修订时间；服务端保留 Admin 权限、幂等键、If-Match 冲突检查和同事务审计。删除后回读列表确认，批量失败保留选中项。读取失败、断网、权限失败和空关联均有明确显示，切换团队时旧请求不能覆盖新团队。

## 验证范围

权限与幂等回归、陈旧修订拒绝、审计失败回滚、存在模板及历史项目引用时删除成功、冻结快照不变、关系查询去重与非主团队识别；补充 Admin 类型检查与页面交互验证。隔离 fixture 中验证删除，不删除线上业务团队作为测试。
