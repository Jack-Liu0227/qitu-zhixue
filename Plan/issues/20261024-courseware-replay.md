# 课件重复演示修复（2026-10-24）

## 用户问题与根因

课件并非一次性资产。此前实验卡把“禁止向旧活动提交证据”和“禁用展示控件”共用 `disabled`：保存观察后活动转向反思、切换课时或完成项目，历史卡的参数和运行按钮也随之禁用。刷新后的恢复接口正确移除了旧卡的写权限，但前端没有单独提供复习演示。

另一个问题是 v2 波动卡的成功请求没有清除幂等键缓存：相同参数再次点击运行时，沿用了上一次成功操作的键，得到的是旧回执。失败重试需要沿用原键，成功后的下一次主动运行需要新键。

## 修复内容

- `WaveOpticsExperimentCard`：区分界面忙碌、证据只读和复习演示。当前活动显示“再次运行并比较”；存在服务端已接受运行的历史卡显示“重新演示”和“重置演示”。复习用现有注册物理模型及参数解析器计算，仍校验远场、缝宽、缝间距等范围；不调用实验写接口，不构造运行回执。
- 已保存的运行与复习计算使用独立状态；重置恢复初始参数和历史图样，复习结果明确标注“不保存”。观察提交表单在历史卡中隐藏；正式实验的 TheoryMastered、当前活动、对象权限和证据校验保持由服务端负责。
- 旧版单缝/散射卡：有已接受运行或观察记录时支持重复演示；没有历史运行依据的预览继续保持受限。只复习该卡既有模式，不扩大旧授权。
- 普通分步课件与板书增加“从头再看”。课件仅将阅读位置设为第一步，`continueLearning: false`，不重复确认完成；板书翻页完全在展示层进行。

未更改导航、模板、掌握度算法、服务端门禁、生产学生事实或数据库结构。开始修改前捕获目标文件基线，并核对远程版本；工作区其他既有改动未覆盖。
