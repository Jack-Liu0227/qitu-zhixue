# 登录与个人注册页面升级

用户要求完成登录、注册页面的 UI 升级。保持 `/login`、`/login?mode=register`、个人注册合同、四类登录身份、后端授权与账号数据不变。已有手机号待开通状态继续按服务端配置显示。

设计采用启途蓝、冷白和浅青灰，正文使用系统中文黑体，左侧探索标题使用宋体风格以形成阅读层次。桌面为项目探索展示与账号表单双栏；复用既有飞行工程情境图，并明确标注示意，既不虚构学生成果，也不创建项目。手机与平板优先展示品牌和表单，不堆叠桌面宣传内容。

登录、注册共用品牌页头、方式切换、按钮与输入规范；简化注册字段外层卡片，增加密码显示控制，保留服务/隐私说明与主动授权。未开通的手机号方式显示清晰说明和返回邮箱按钮，不让用户填写不可提交的表单。保留 loading、错误重试、断网、权限失败、成功反馈及快捷账号空态。

验证使用隔离注册 fixture 和 Playwright 检查邮箱注册、登录、角色选择、密码可见性、快捷账号、请求失败与断网；检查 320/390/768/1440 像素布局、键盘焦点、减少动态效果偏好和页面图片。部署只更新登录应用及本次文档，保留 Tutor、教学合同与其他管理端并行改动。
