## 验收边界

浏览器使用本地 Next 页面、隔离内存 API 与合成投影。Tutor、矩阵失败注入和家长乱序测试不访问真实学生数据、生产模型或生产写接口。截图中的 Fixture/Synthetic 是合成测试内容。

真实 iOS/Android 软键盘、辅助技术、完整 WCAG 合规与生产模型请求需要目标设备或发布环境复验。本次没有宣称这些检查通过。尚未接入的统计明确呈现“暂未接入”。

冻结导航、Admin 全局控制、对象权限、项目确认与 TheoryMastered 门禁均保留，没有新增平行项目或掌握度状态库。
