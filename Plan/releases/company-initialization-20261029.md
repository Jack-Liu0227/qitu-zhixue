## 问题与处理

用户反馈 Company 无法开展实际工作。现场管理员登录、Company API 和数据库读取正常；但 12 个部门均未绑定助手，没有可执行的公司任务。产品未绑定课程，订阅及销售开关关闭，微信商户配置不完整。页面发布成功并不代表各项经营能力已经初始化。

本次通过现有、带权限校验及幂等控制的 Admin/Company API 完成配置，未直接修改数据库：

- 在 Admin 新建 12 个公司专用助手，逐项采用 `COMPANY_DEPARTMENTS` 的部门与职责。模型供应商及模型来自现有启途管家的有效配置，保留完整 provider/model 对；不复制密钥、不修改原有教学助手。
- 公司助手不绑定教学技能、外部工具或 MCP，不进入教学团队可选列表。其职责为根据经营汇总生成内部可审阅成果。
- 将每个空部门绑定至对应专用助手并启用，逐项回读绑定、开关和 revision。初始化脚本遇到已有绑定时保留，不覆盖。
- 保存真实的《Company 工作区使用与初始化边界》知识条目。当前知识目录供人工查阅，不宣称任务执行器已经自动检索这些条目。
- 委派实际内部工作《公司初始化核查与运营启动安排》。任务 `ce872e0c-d71d-4b37-93cc-42f2ebdcf7ce` 经真实模型请求一次执行成功，保存了 1747 字符的成果。其他部门完成配置回读，但未逐个发起付费模型请求。
