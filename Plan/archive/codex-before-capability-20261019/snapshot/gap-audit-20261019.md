### F02 — 16 课时多份真源，版本 ID 没冻结内容

证据：`packages/contracts/src/curriculum.ts:175`；`services/api/src/modules/templates/content/optics.ts:30`；`services/api/src/modules/templates/content/optics.ts:309`；`services/api/src/modules/learning-plan/optics-plan-generator.ts:99`。

契约常量、服务端模块表、ai-client 目标/排期并存；服务端 `OPTICS_SESSION_MODULES` 默认已指向 16 节，bootstrap key 仍为 `optics-physical-inquiry:v1`。生成器只接收版本 ID，实际使用编译时全局常量，不能保证旧版本内容不随代码变化。

补齐：唯一 `ProjectTemplateSpec` 版本 envelope；生成器消费实际 frozen content/hash。16 节用新 bootstrap identity/模板版本；多排期必须冻结审核 profile。旧 v1 不原地变义。目标可跨复习课重复，16 节不等于 16 新 mastery 目标。

### F03 — 深绑定方法仍是未接线的危险占位

证据：`services/api/src/modules/templates/templates-binding.service.ts:500`；`services/api/src/modules/team-runtime/team-runtime.service.ts:562`；`services/api/src/modules/team-runtime/team-runtime.service.ts:594`；`packages/contracts/src/curriculum.ts:126`。

`resolveDeepTeamBinding` 用成员 ID/role 正则猜助手，缺失则固定 fallback，并硬编码光学/运动两库；返回 hash 不覆盖新合成的 map/grant。`resolveSessionAgent` 使用全局数字范围，`canAccessImaKnowledge` 未传授权时默认允许两库。检索未发现这三个方法的生产调用点。

只读复现：`getPhaseAndRoleForSession(0/-1/17/NaN)` 返回评审阶段，1.5 返回探索阶段，不拒绝非法索引。`gateCondition: ... | string` 也未保留闭集。

补齐：roleMap/grant 来自快照并入 hash，角色须是真实成员；按该版本的实际 sessions 解析，不靠正则/全局 1–16/fallback。边界拒绝非法、缺映射和缺授权。

### F04 — IMA 已有平台/桥防护，但缺项目授权交集

证据：`services/api/src/modules/ai-tutor/ima-mcp.client.ts:165`；`services/api/src/modules/platform-registry/ima-settings.service.ts:110`；`services/api/src/modules/ai-tutor/tutor.service.ts:1380`；`packages/contracts/src/project-binding.ts:82`。

但 Tutor 直接工具授权不接收 project/KB/document，`arguments: args` 原样转发；DTO 可选 imaGrant 未进入 SnapshotRecord、DB store、toSnapshotView/hash。桥允许某库不等于这个项目允许。

补齐：冻结项目 grant ∩ 当前 Admin 全局授权 ∩ 当前助手/工具授权 ∩ 对象权限。搜索/列文档校验或注入 KB；列库过滤；读文档核验其签名引用对应 KB/project 的服务端 provenance。opaque token 不能由模型/浏览器自行声明归属。撤权立即阻断，新增权限不扩大旧项目。引用过期/重启后安全重新检索。

### F05 — 实验识别漏掉真实模板，动作字段没有落库闭环

### F07 — 物理模型与证据文案有误导

证据：`apps/student-center/features/tutor/components/OpticsDiffractionScatteringCard.tsx:101`、`:109`、`:337`、`:428`。

补齐：区分模拟和测量、先预测再读数、展示坐标/单位/近似域，域外停止定量断言。详见光学方案。
