# 中学生项目案例展陈（#56）

## 设计边界

首页主张是「一个问题，长成一件作品」。采用白垩底色、钴蓝主色、深蓝文字与有实体质感的校园模型，替代粒子、光晕和虚构进度。公开站点用衬线展示标题，角色工作区用清晰的中文无衬线正文。保留所有冻结导航、数据来源、状态门与权限合同；不把首页视频搬进业务工作区。

五个应用根布局最后导入 `@qitu/ui/brand.css`。核心 token 在 `packages/design-tokens` 与 UI CSS 中同步维护：页面 `#F4F7FB`、主色 `#0038B2`、标题 `#132646`、正文 `#30435F`、次要文字 `#566780`、边框 `#DDE5F0`。状态色仍表达语义，不强行染蓝。家长、管理端手机抽屉与桌面收起状态独立，切换路由、进入窄屏与 Escape 关闭抽屉。

## 故事与三组九幕剧本

故事：「把一个好问题，做成一个能解释世界的作品」。首页不再用单一校园环保案例，而是并列展示三个更接近中学生的项目：无人机工程、桌面机器人、光的衍射与散射。每组有提出问题、搭建/实验、测试/讲解三个时刻；同一高位镜头、白垩底色和钴蓝色确保案例像同一个学习平台里的作品展，而不是九张无关插画。

| 项目 | 时刻 | 画面 | 学习含义 |
|---|---:|---|---|
| 无人机工程 | 0/3/6s | 稳定航向问题、原型搭建、安全笼测试 | 把空气动力、控制与安全变成可验证的工程变量 |
| 桌面机器人 | 9/12/15s | 读懂房间、拆解结构、搬运方块 | 让传感器、代码和机械结构协同工作 |
| 光的衍射与散射 | 18/21/24s | 窄缝提问、明暗条纹与雾室、物理讲解 | 把高中物理概念落到真实装置和证据 |

章节文本、图片替代描述与时间在 `apps/auth-portal/app/home/storyboard.json`。画面不含真实儿童、学生数据、成绩或可识别人物。提示词见本目录 `project-cases-prompts/`。

## 素材来源与合成

- 按用户指定的本机 ImageGen skill，通过 Python OpenAI SDK 调用 `gpt-image-2` 生成 2048×1152 PNG；凭证只保存在本机 skill 配置，不进入仓库。
- 共生成九幅：无人机、桌面机器人、光学实验各三幕，使用同一高位镜头和材质约束；没有把真实儿童或真实课堂数据放进素材。
- PNG 原稿与运行输出保存在被忽略的 `output/imagegen/`，生产仅提交九张 WebP 和 MP4，避免把运行配置或大体积原稿带进仓库。
- `python tooling/build-story-film.py` 使用 Pillow 和 ffmpeg：每幕约 3 秒、轻微推近、八次 0.35 秒叠化，合成 27 秒、1280×720、30fps、H.264、无音轨、faststart 视频。
- 这是**生成静帧合成视频**，并非原生文生视频，也不是真实学生学习录像。页面明确标注此边界。相邻画面叠化不等于真实流体或物理仿真。

## 播放与可访问性

静态首帧与完整文字优先。支持播放/暂停、三个项目案例切换和九章跳转；选择章节会暂停。系统或产品减弱动态偏好关闭视频源，节流偏好默认静态，需主动播放。离屏、页面隐藏或离线时暂停；视频失败保留分镜、文字与重试入口。无音轨，无自动播放声音。案例按钮、章节按钮、键盘焦点和替代描述保留。

## 验证与风险

- 自动化：`pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build`；`tooling/brand-story.test.mjs` 随 UI 测试运行，检查三组九幕资产、时间、项目主题、包体预算与五应用共享样式导入。
- 浏览器：使用 Playwright skill、网站自带演示账号，只读检查首页与四角色入口；桌面 1440px，手机/平板 320、375、414、768px。演示截图放系统临时目录，不提交含账号界面的截图或会话凭证。
- 部署后必须实际检查 CSS/JS、九张图片、视频及 Range 请求，而不是只看 HTML 200；执行 `tooling/check-frontend-assets.py` 与线上 Playwright 回归。
- 不增加数据库迁移、API 写接口、模型调用或权限范围。角色页面原有 loading、empty、error、offline 与权限失败流程不变。主要风险为跨应用 CSS 级联与低带宽视频加载，分别通过共享层末尾导入、真实截图和静态降级约束。
